# 固定读出与参考方差来源的独立诊断

这项诊断在原动态边界实验揭盲后进行。沿用 14 个已冻结的强 MLP、原两轮各自的 STATE-CAL 仿射系数、原 REF 抽样规则及原 TEST 归档。重新计算原有 CAL 和 REF 的矩用于验证。新数据仅用于估计总体校准误差和总体方差，不训练、选择方法或生成新测试轨迹。

两个新面板分别使用主种子 2026111501 和 2026111502，角色 61，各 131,072 个独立标准四维高斯状态。所有 checkpoint 与原规范共享这些状态以便配对；不同面板的随机流独立。编码分块 8,192 状态，CPU 最多两线程。对每模型每原轮次，估计 $c_j=\operatorname{Cov}(Z_j,e_j)$、$v_j=\operatorname{Var}(e_j)$、$\sigma^2_{V,j}=1+2c_j+v_j$，其中 $e_j=V_j-Z_j$。合并两个面板，另外保存各自估计。用 iid 影响函数协方差给出合并估计的逐项正态近似 95% 区间，同时估计原 32,768 样本经验方差的标准误，后者使用读出四阶矩而非预设正态方差公式。

对预先指定的原首轮窄间隔过程、宽谱分离 seed1942、零基 row18、真快轴1减真慢轴2，用封存的物理分数、经验参考方差和交叉/能量分项。把原参考项逐轴精确写成 $R_j=-D_j(2c_j+v_j+\delta_j)/S_j$，其中 $\delta_j=S_j-\sigma^2_{V,j}$。采用估计的总体矩时，此为代数闭合，只有各子项的经验归因带不确定性。用对应的跨轴联合影响函数传播不确定性；区间只描述新 iid 矩估计，原参考的实现值、校准、模型和该窗口固定。另外按同一原 REF 行计算 $S_j-1=(\widehat{\operatorname{Var}}(Z_j)-1)+2\widehat{\operatorname{Cov}}(Z_j,e_j)+\widehat{\operatorname{Var}}(e_j)$，此为完全经验的补充核对。

对每轮所有 28 个固定模型—过程组合，在已封存窗口上汇总每轴子项和所有物理 top-2 跨界对差的 RMS，并同时报告原交叉、能量分项。以物理入选轴和未入选轴的四个组合做差；报告汇总和指定窗口结果，不把它们当作额外独立测试。总体矩为估计，窗口项为已观察历史量。校准标签、冻结模型和四维 Gaussian AR(1) 条件限制解释范围，不据此改写原机制门或推出因果归因。
