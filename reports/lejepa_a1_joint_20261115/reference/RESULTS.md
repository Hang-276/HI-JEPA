# 独立状态面板核对参考方差

用两份各 131,072 个 iid 状态的独立面板，重新估计 14 个冻结强 MLP 在原两轮 CAL 坐标下的总体矩。重放核对了原来的 CAL 仿射参数和经验 REF 方差。只分析已归档的测试慢度分项，未生成新测试轨迹。

## 已存第 18 个索引窗口

首轮窄间隔过程、编码器 `separated_wide_1942` 的零基窗口 18 中，物理第 1、2 轴的实际窗口分数为 1.64320 和 1.64125。原读出经验参考方差 $S_1,S_2$ 为 1.01609 和 .99585。所得参考项差为 −.032866。

| 固定 CAL 坐标下的量 | 物理轴 1 | 物理轴 2 |
|---|---:|---:|
| $c_j=\operatorname{Cov}(Z_j,e_j)$ | −.000239 | +.000148 |
| $v_j=\operatorname{Var}(e_j)$ | .004063 | .002050 |
| $\sigma^2_{V,j}=1+2c_j+v_j$ | 1.003585 | 1.002345 |
| 原经验参考减估计总体方差 $S_j-\sigma^2_{V,j}$ | +.012509 | −.006495 |

在原经验分母 $S$ 上，参考项差分解如下。95% 区间只反映新状态面板估计总体矩的蒙特卡洛误差，原 CAL、REF、窗口及模型保持固定。

| 参考项的来源 | 轴 1 减轴 2 | 近似 95% 区间 |
|---|---:|---:|
| 同轴协方差 $2c$ | +.001259 | [−.000147, +.002664] |
| 残差总体方差 $v$ | −.003191 | [−.003367, −.003015] |
| 经验 REF 偏离总体方差 $\delta_{\rm REF}$ | −.030934 | [−.032335, −.029533] |
| 合计 | −.032866 | 由原分数和经验方差精确决定 |

该窗口的参考项差主要来自原 REF 方差的这次实现。直接在原 REF 样本上做恒等分解也得到相同结论。物理样本方差偏离 1 的贡献为 −.033847，样本同轴协方差贡献 +.003906，样本残差方差贡献 −.002925。由独立面板四阶矩估算，两个读出轴原 32,768 样本经验方差的标准误分别约为 .00772 和 .00785。

## 全面板中的量级

下表对每轮 28 个固定模型／过程组合的封存窗口，计算真实慢集内外四个轴对的分项差 RMS。RMS 只描述分项量级。各项可以相关、抵消，RMS 不应相加或转成唯一贡献率。

| 分数分项的跨界差 RMS | 初轮 | 复验 |
|---|---:|---:|
| 动态交叉 $K/S$ | .07668 | .07470 |
| 残差动态能量 $E/S$ | .05985 | .05429 |
| 整体参考项 | .03854 | .04307 |
| 参考项中的同轴协方差 $2c$ | .00177 | .00178 |
| 参考项中的总体残差方差 $v$ | .03891 | .03855 |
| 参考项中的有限参考偏离 $\delta_{\rm REF}$ | .01960 | .00965 |

残差总体方差项在全档案跨界 RMS 中大于有限参考项，而指定窗口呈相反情况。因此总体上的分项量级不能替代单窗口归因。14 个固定模型和四轴的 $|c|$ 中位数在两轮分别为 .000350 和 .000224，最大值为 .001841 和 .001767。原参考方差标准误的模型轴中位数在两轮均约为 .00775。本诊断只覆盖这批冻结读出、两个原 CAL／REF 和标准四维高斯边际，原前瞻检验判定保持独立。
