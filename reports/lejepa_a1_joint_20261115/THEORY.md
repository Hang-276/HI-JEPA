# A1：局部状态在什么误差结构下有解释力？

当前目标是选出同一段轨迹中真实慢度分数最低的两个命名因素。窗口长 193，按 4、16、32 步分别求平方增量均值，再等权平均。下面先用可解的残差模型检验窗口状态均值是否有解释力，再说明它与选取可靠性的关系。

## 窗口均值能解释同轴二次误差，对独立跨轴线性混入则几乎无效

设真实因素为平稳标准高斯 AR(1)，在固定读出坐标下，定义交叉项 `K = 2 avg(ΔZ Δe)`，`avg` 使用上述时间权重。若误差为 `e = β(Z²−1)`，则对每个端点对 `(a,b)`，令 `X = Z_a+Z_b`、`Y = Z_b−Z_a`，得到 `K = 2β avg(XY²)`。因此交叉项取决于按变化能量加权的端点位置，普通窗口均值只是它的代理。

令 `M` 是窗口真实状态均值，`s² = Var(M)`，`q_t = Cov(Z_t,M)/s²`。记 `p=q_a+q_b`、`d=q_b−q_a`，`u=Var(Y)=2(1−ρ^(b−a))`。条件高斯公式给出 `E[X|M]=pM`、`E[Y|M]=dM`、`Var(Y|M)=u−s²d²` 和 `Cov(X,Y|M)=−s²pd`。展开条件三阶矩，

```
E[K | M=m] = 2β [A m + B m³]
A = avg(p (u − 3 s² d²)), B = avg(p d²).
```

对两个端点对（可来自不同时间间隔），每对的 `X` 与 `Y` 自身不相关。高斯乘积矩给出

```
Cov(XY², X′Y′²) = Cov(X,X′) [Var(Y)Var(Y′) + 2Cov(Y,Y′)²]
                    + 4Cov(X,Y′)Cov(Y,X′)Cov(Y,Y′).
```

用全部端点对的权重计算 `Var(K)`，包含重叠和时间间隔之间的协方差。结果是：在本项目两种评价动力学的六种 `ρ` 下，若残差只有这一个非零二次分量，**真实窗口均值可解释 68.1%–70.2% 的交叉项方差**。这是 `Var(E[K|M])/Var(K)`，不是单窗符号命中率。即使知道真实均值，也仍有约三成交叉项方差无法由均值解释。

对照残差 `e_j=βZ_k`，其中两个物理因素独立。这时 `K=2β avg(ΔZ_j ΔZ_k)`。独立性给出 `E[K|M_j,M_k] = 2β avg(d_j d_k) M_j M_k`，而乘积的协方差是各因素增量协方差的乘积。在三个代表性目标轴／混入轴速率对上，**两轴真实窗口均值合用，解释比例也只在 0.0007%–0.0021%**。这里丢掉的主要是两条轨迹的变化是否在相同时间发生、方向是否相同。该结果只针对单一独立线性混入和只看窗口均值的设定。

数值由精确高斯矩计算，未采样或拟合 LeJEPA。脚本用两时刻特例校验，纯二次项解释比例为 1/3，独立线性混入为 0。[代码](analytic_window.py) · [数值](ANALYTIC_WINDOW.json)

## 这如何影响慢因素选取

对固定读出，将其中心化后写成 `V_j = a_j Z_j + u_j`，其中 `u_j` 与 `Z_j` 在总体上正交，`v_j=Var(u_j)`，`σ_j²=a_j²+v_j`。`D_j` 是当前窗口的真实分数，`N_j(V)` 是读出的平方增量均值，`S_j` 是原独立参考样本方差。恒等式

```
N_j(V)/S_j − D_j = [2a_j avg(ΔZ_j Δu_j) + avg((Δu_j)²) − v_j D_j]/σ_j²
                     + N_j(V) (1/S_j − 1/σ_j²)
```

将读出自身的动态失真和只换参考分母产生的偏移分开。第一项的交叉部分总体均值为零。若 `u_j` 展开为正交 Hermite 模态，系数为 `b_α`，模态单步相关为 `η_α=∏ρ_i^α_i`，定义 `d(η)=2 avg_h(1−η^h)`，则第一项的总体均值为 `Σ b_α²[d(η_α)−d(ρ_j)]/σ_j²`。因此即使状态残差方差相同，总体偏移也可能因混入模态更慢或更快而异。有限窗口的交叉项又取决于残差形式，不能由总体方差或偏移均值替代。

对真实入选轴 `i` 与未入选轴 `j`，设真实间隔至少为 `m₀>0`。如果在这一事先定义的窗口条件下，相对分数误差的条件均值不小于 `−b`、条件方差不大于 `s²`，且 `b<m₀`，那么单侧 Chebyshev 不等式给出翻转概率上界 `s²/(s²+(m₀−b)²)`。这里不要求误差与间隔独立，但需要同一窗口条件下的矩界。无测试真值时的应用还需要可观测条件和独立校准证据，完整的 top-2 判断须同时考虑所有入选和未入选轴之间的比较。

所以真实窗口均值解释了某种残差的交叉项，并不直接说明它足以决定选取。实际 LeJEPA 检验要看预先拟合的二次分量在独立轨迹上能否解释**两条候选轴之间**的误差差值，以及扣去它会修复多少错选、又新增多少错选。
