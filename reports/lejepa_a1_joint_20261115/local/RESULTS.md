# 有限窗口的二次残差机制检验

原冻结的 14 个强 MLP 在两个原物理过程上，用两批新数据各评分一次。每轮使用独立 32,768 个带标签状态估计残差的低阶多项式，每过程 1,024 个新测试窗。沿用原轮次冻结的仿射坐标和 REF 方差。所有二次项诊断都使用了物理 TEST 标签。

## 跨界交叉项

相对冻结 CAL 均值，以下数值为归一化跨界交叉项 (K_j/S_j-K_i/S_i) 的 MSE 相对下降。每个窗包含四个真实慢集内外配对。

| 分量 | 首轮点估计 / 单侧 95% 下界 | 复验点估计 / 单侧 95% 下界 |
|---|---:|---:|
| 全部二次项 | 15.91% / 11.39% | 13.96% / 8.70% |
| 同轴二次项，按增量平方加权的端点均值 | 15.02% / 10.87% | 14.22% / 10.27% |
| 同轴二次项，给定普通窗口均值的条件均值 | 10.01% / 7.37% | 9.85% / 7.37% |

前两项均通过预锁门（点估计至少 10%，下界大于 0，两轮分别通过）。全部二次项的跨界符号一致率为 58.64% / 57.87%，CAL 均值为 49.94% / 49.51%。全部二次项的 MSE 降幅集中在两个以 1942 为训练种子的 crossed MLP。描述性地，两模型贡献 88.4% / 88.3% 的总平方误差下降。其余 12 个模型单列后降幅为 6.19% / 5.40%，同轴加权项为 2.51% / 2.66%。这个分组由结果揭示，完整面板的预锁判断照原规则报告。

## 真实 top-2 与原交叉项的保护作用

| 分数扣项 | 首轮 top-2 增益（百分点） | 复验 top-2 增益（百分点） |
|---|---:|---:|
| CAL 均值 | −0.010 | −0.091 |
| 同轴普通窗口均值 | −0.003 | +0.017 |
| 同轴加权端点均值 | +0.157 | +0.066 |
| 全部二次项 | +0.038 | +0.021 |
| 真值全交叉项 | +2.815 | +2.853 |

原分数的 top-2 正确率为 93.872% / 94.496%。全部二次项重现了真值全交叉项扣除所修复的跨界对中的 274/1,351 和 260/1,422，也重现了全交叉项扣除所损害的跨界对中的 61/425 和 50/453。同轴加权项相应为修复 240/1,351 和 213/1,422，损害 36/425 和 36/453。两类对由真值反事实定义，只用于检验误差分量怎样推动边界。

该结果支持二次项在此固定面板上解释一部分有符号交叉波动，尤其是原误差较大的两个读出。其余波动仍占大头，且扣除该分量几乎没有改变整组慢因子选择。没有测试用可见窗口均值或其他无真值特征进行部署。置信下界条件于固定模型与 CAL/REF。
