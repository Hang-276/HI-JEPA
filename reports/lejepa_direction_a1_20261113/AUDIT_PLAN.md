# A1｜慢集对恢复误差方向敏感性的设计审计

日期 2026-11-13。只涉及[研究待办 A1](../../docs/ICML_RESEARCH_TODO.md)的验证设计。旧研究已经展示同精度的正负旋转和较低增量 MSE 可以得到不同选集，并在一个受控系统用 CAL 成功预测不利方向。真实冻结 Fine 的旧方向规则在相近精度的成败对上与幅度规则持平。新的信息应是：用独立 CAL 的信息提前分辨新窗口的危险轴对与扰动范围，以及明确在哪类实际训练表示上失效。 [受控方向预测](../stage_a_plus/step5_local_20261105/RESULTS.md) · [冻结 Fine 的历史预测](../stage_a_plus/step6_fine_20261105/RESULTS.md) · [动态损失复验](../lejepa_dynamic_transfer_20261113/RESULTS.md)

## 最小实验与信息边界

1. **受控方向干预。** 固定物理轨迹、总体目标方差、参考样本及读出预算，选择 CAL 上事先定下的跨边界不利方向、等幅有利方向和块内负控。在 CAL 确认两臂逐轴状态 MSE 或 R²、误差能量的差异是否落入预设容忍度，同时记录参考设计相同且每个读出使用自己一致的参考方差。总体正交或对称的合成设计可给出精确等误差。真实冻结读出原有误差会与注入扰动相互作用，正负角的名义大小相同不推出恢复误差相同。实际 TEST 恢复差异需作独立诊断，并保留未匹配的预设组合。
2. **实际冻结 LeJEPA。** 至少用两个事先指定的 checkpoint 或条件和新的独立轨迹评估两类比较。第一类是在模型读出的命名坐标上干预混入方向，检验训练表示受到该干预后的排序变化。第二类保留不加扰动的自然残差，用同一预测口径检验是否能提前定位原读出自己的错选。如果第二类未过判据，第一类仍能说明特定冻结表示对方向敏感。它无法单独解释原模型为何自然出错。CAL 如用物理标签，明确表述为有限监督下的预测性诊断。若 CAL 为无标签/命名扰动接口，报告其额外假设。
3. **阶段封存。** CAL 物理标签用于估计误差方向、危险对和阈值，冻结模型、角度／幅度档位、预测规则、匹配阈值和允许拒答条件。预测时仅取得新轨迹观测或冻结表示，并用固定规则估计物理答案相关的危险对与安全范围。预测与评价真值分别保存，先封预测再重放 TEST 物理标签。以 TEST 真值代入分子分母误差恒等式和事后选择最严重的轴对只作机制定位。
4. **区分两个预测目标。** 总体分数比较可用 CAL 的总体矩预言哪条分支在某个幅度区间翻转，再检验独立样本汇总的符号与首次翻转区间。若目标为逐窗口预测，有限窗口交叉矩会变号，CAL 固定方向不能代替窗口信息。需要利用当窗可见动态，评价该窗的物理边界或预计翻转是否正确。直接从待测表示计算不同扰动的两个预测集合，回答的是输出会不会变，仍须使用独立物理真值核对哪个集合正确。

## 预设对照和验收

- 固定 lag 4/16/32 及同一命名物理 top-2；逐窗口保留所有真实跨边界轴对的符号。候选危险对可由预先规则给出，并核对预测的失效轴对是否为实际倒序对。若定义“最先翻转”，在固定的扰动网格记录最早变号位置及多对并列处理。不要根据 TEST 结果调整网格或只报告物理第 2、3 名。
- 方向规则与同信息的**幅度对照**（保留相同 CAL、轴恢复和动态规模，去掉或打乱有符号交叉项）及**名义预测间隔**比较。预设一项主效果，例如方向规则在新轨迹上提高危险轴对或翻转符号判别；记录实际错误数、可作答分母、与基线配对差及不确定性。控制有利、块内方向的跨界假阳性。对已封存的安全区另报覆盖和物理错选，不能把没有作答的规则记为正确。样本少或安全区空时保留未分辨结论。无需把旧 5% 门槛挪到 A1。
- 用整条轨迹或独立 CAL/REF/TEST 面板作统计单位。保留所有方向及模型的成对窗口。报告误差匹配组和全部组合，并标明条件于当前固定 checkpoint；同一模型的扰动重复不构成独立训练重复。
- **建议勾选的证据。** 独立受控测试支持在近似等恢复误差和同参考设计下，对危险轴对、翻转幅度区间及安全侧的事先预测。该预测也能在实际冻结 LeJEPA 的新轨迹上以相同信息超过上述对照，或得到预先声明并独立验证的失效边界。若只复现受控翻转、只看到训练表示对人为扰动敏感、或只有揭盲后恒等式能定位，则记录 A1 的部分进展，保留未解决的自然残差预测。完整因果归因到训练优化过程、广泛新训练初始化以及无真值可部署证书可在后续项目处理。
