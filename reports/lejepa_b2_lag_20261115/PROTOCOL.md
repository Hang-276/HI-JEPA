# B2：只替换解混校准的时间间隔

固定 A4 新面板的八个封存 LeJEPA 编码器和两个原评价过程。每个种子与评价过程独立生成一套校准和测试数据，同种子的两种训练条件共用对应数据。每套含 1,024 条校准轨迹、256 个命名锚点、32,768 个独立参考状态、16,384 个独立带标签审计状态、4,096 条新测试轨迹。轨迹长度 193。所有数据角色使用独立随机流。

每个组合对同一套校准嵌入估计零滞后协方差，用同一对称白化矩阵。分别对称估计 lag 1、4、16、32 的白化滞后协方差，并分别对角化。多 lag 臂先把这四个白化矩阵等权平均，再只对平均矩阵做一次特征分解。五臂共用命名锚点和成对的 ±0.15 物理干预。命名使用旧规则，按候选列的响应范数归一化后最大化四个匹配响应之和。名义状态坐标在同一 CAL 中心平移后按各自的被命名轴响应缩放。命名锚点、判断规则和状态缩放方式固定，得到的变换可以因校准滞后不同而变化。

预测分数以相同的 4、16、32 步增量矩等权平均为分子，除以由同一套独立 REF 状态在对应坐标下估计的方差。同轴非零缩放在分子分母中抵消。真实物理轴使用已知单位方差。评价为逐窗真实命名 top-2，任一入选轴不一致均记错。独立状态审计记录命名响应、物理轴 2/3 的相关平方、命名后直接 (R^2)、物理前向线性载荷及非对角载荷。

## 预定对照与时间间隔的预测

首要比较窄间隔过程上的 lag 16 与 multi 分别对 lag 1 的 top-2 变化。两对照分别要求点估计至少提高 1 个百分点，且对这两个对照 Bonferroni 后的单侧 bootstrap 下界大于 0。每个种子在同一轨迹上先平均两种训练条件的配对差，再独立对每个种子的完整轨迹行重抽样并取四个种子等权平均。区间条件于固定模型和 CAL/NAME/REF，任何训练种子泛化都不由该区间支持。逐组合和逐种子效果、宽间隔和其他 lag 都作描述。

在理想线性可逆独立 AR 混合中，单滞后的物理特征值为 ρ 的对应次幂，多 lag 特征值为四个次幂的均值。这些矩阵共享特征方向。放大间隔有助于分辨接近的轴，仍须相对估计误差足够大。对每臂计算轴 2/3 到最近别轴的最小理论距离；再用配对的 64 次 CAL 整轨迹重抽样估计白化滞后矩阵 90% 算子范数扰动。事前诊断规则预测理论距离除以扰动的比值越高，重抽样的命名轴方向越稳定。用独立状态审计另外核对物理轴恢复方向，并报告单 lag 矩阵的交换子。白化模型、噪声诊断和物理谱的关系有线性混合前提。非线性编码器可能压缩因素或把不同动态模态混在同一坐标中。诊断比值仅用来解释结果，不替换主比较、不依赖 TEST 标签、不提供有限样本证书。

协议、配置、代码、检查点和可见 TEST 预测作散列封存。只有验证封存记录后才重放物理 TEST 真值。结果按原规则汇报，不补充筛选或滞后网格。
