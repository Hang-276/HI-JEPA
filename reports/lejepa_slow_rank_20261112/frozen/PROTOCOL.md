# 冻结 LeJEPA 的独立窗口复评

预先固定原 AR rich case A 与原 FHN case A ε=.08，以及各自历史无标签 CAL 所选的三个 LeJEPA checkpoint。按原模拟器、物理参数与观测混合生成新数据，使用独立 RNG tag。旧 TRAIN/CAL 观测仅用于核对模拟器与 checkpoint 前向复现，旧 TEST/FINAL 数组不读。独立校准 96 条有标签轨迹拟合两个固定读出。每种动力学另设 8 个独立面板，各有 64 条独立参考和 64 条独立评价轨迹。一个完整轨迹是一窗口。

主指标为 lag 4/16/32 等权增量平方均值除以对应坐标在独立参考面板上的经验方差。真实选集取当前窗口分数最低的两个命名因素。按物理轴顺序稳定排序处理平局。读出有两个，四维稠密仿射回归与最大绝对相关一对一分配后逐轴仿射回归。编码前的 raw 观测使用完全相同的校准标签、参考数据和读出作为对照。两条读出都是有标签机制诊断，评价物理标签在预报封存前不可用于读出或预测。报告四轴最小与平均验证 R²、直接 top-2 错选、真实 gap≤.05 分层和间隔 MAE。间隔误差使用预测对真实第 2 与第 3 名物理轴的有符号分数差。

先封存每窗口预测增量、预测分母、选集、误差计算所需读出与观测流标识。评分时独立重放物理参考与评价，验证观测哈希后，做物理增量/估计增量 × 物理方差/读出参考方差的 2×2 事后对照。面板内三模型共享轨迹与参考，结果显示逐模型计数和按独立面板配对重采样的描述性区间，模型 seed 不视为独立轨迹。R² 用评价真值仅用于揭盲后读出诊断。Oracle 替换为事后归因。无模型更新或超参选择，无总体方差证书或无真值保证。
