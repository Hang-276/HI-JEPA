# 揭盲后点预测误差诊断

在已揭盲的 8,192 个 AR 窗口上复用原 checkpoint，保持窗口和 $V_j=1$ 的物理答案固定。重放原先的参考方差、谱解混和命名结果，逐轴预测分数与封存值在绝对误差 $10^{-10}$ 内一致，所有窗口预测集合完全一致。下表各替换只作事后诊断。

| 替换 | 命名 top-2 准确率 | 相对原规则 |
|---|---:|---:|
| 原 128 条校准轨迹、原参考、命名扰动 | 65.87% | — |
| 原校准、原参考、按已知物理速率次序命名 | 59.09% | −6.77 个百分点 |
| 原校准、2,048 个独立平稳参考状态、原命名扰动 | 66.15% | +0.28 个百分点 |
| 原校准、32,768 个独立平稳参考状态、原命名扰动 | 66.82% | +0.95 个百分点 |
| 1,024 条新无标签校准轨迹、原参考、原命名扰动 | 70.64% | +4.77 个百分点 |
| 1,024 条新无标签校准轨迹、32,768 个独立平稳参考状态、原命名扰动 | 71.42% | +5.55 个百分点 |

已知物理速率次序给出物理轴标签的排列，给潜在特征向量赋名仍需要潜在模式与真实轴对应。它会受到谱交错、轴混合和样本扰动影响。在 64 份校准组合中，原扰动命名有 12 份和速率排序给出的命名不同。整体上，仅改为速率次序命名增加了错误，宽间隔谱交错条件则有约一个百分点的改善。

使用 1,024 条独立的新无标签校准轨迹时，宽间隔谱分离、宽间隔谱交错、窄间隔谱分离、窄间隔谱交错的准确率分别提高 9.33、5.96、3.77、0.05 个百分点。测试中，增加校准轨迹带来的整体变化大于单独更换参考。扩大校准同时重新估计谱坐标和由原命名扰动选择的排列。这些替换不能把残余错选唯一归因到某一个误差来源。完整比较包括两种命名、三种参考和两种校准设置。 [诊断统计](point_localization.json)
