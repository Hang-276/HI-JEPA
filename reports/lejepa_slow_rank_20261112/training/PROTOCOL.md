# Controlled CPU LeJEPA slow-set experiment

The four fixed conditions in `protocol.json` vary the one-step linear/nonlinear spectral gap and the population physical top-2 gap independently. The generator is an independent Gaussian AR(1) per axis with stationary variance one. All conditions use the same invertible triangular nonlinear observation map followed by a fixed orthogonal mixing. Training uses fresh stationary parent-child pairs with actual correlations set to the listed rates. Seeds within each condition are four independent repetitions. Initialization, pair innovations and held-out panels are paired across conditions at the same seed. The CPU experiment uses the locked author's MLP constructor and the unmodified alignment and SIGReg functions. Network width, number of hidden layers, projections and steps are reduced for the local experiment. Final-step weights are fixed. The implementation is an adaptation of the author objective to our generator, with no predictor.

Each run uses separately seeded, mutually independent streams for the online training pairs, unlabelled calibration trajectories, reference trajectories, evaluation trajectories, and the named perturbation panel. The whole evaluation trajectory is one window. An oracle least-squares readout and Hermite diagnostic may access calibration physical factors. Those quantities cannot choose checkpoints or influence named-anchor readouts. The named-axis matching uses sixteen paired interventions per factor at a fixed ±0.15 dose, and maximizes summed normalized absolute response over permutations. Compare the raw representation with only that permutation to a whitened lag-1 spectral rotation with the same matching rule. Fit the lag-1 eigensystem on unlabelled calibration only. Also report a spectral readout with population-order naming as a structured diagnostic and the full oracle linear readout. Score each representation's squared increments at lags 4, 16, and 32 with its own reference variance from the same independent reference panel. Main endpoint is agreement with the physical named top-2 computed from the evaluation windows and their empirical physical reference variance. The population Gaussian scores and population ranking are auxiliary analytic quantities.

Report per-seed named top-2 accuracy and per-factor oracle out-of-sample linear decoding R². The Hermite diagnostic reports held-out linear decodability of the normalized second Hermite polynomial of the slowest factor from the representation. It also reports the representation energy explained by adding each axis's normalized degree-2 feature to a forward linear fit from the four factors. A reduced fastest-factor R² together with increased second-Hermite decoding/energy is the signature of substitution, while isolated variation in one quantity is ambiguous. The result summarizes paired means and seed ranges. Four seeds provide limited information about training variability. Report disagreements and negative results without changing the fixed cases or thresholds.

An analytic whitening-relaxation control selects the top four nonconstant Hermite functions from the known spectrum and records whether all four physical linear axes are included. At these specific rates, degree-1 and degree-2 candidates suffice for the top four because the fourth selected eigenvalue exceeds the maximum degree-three eigenvalue. The control describes the population alignment problem with exact whitening. Training with SIGReg and a finite network is evaluated separately.
