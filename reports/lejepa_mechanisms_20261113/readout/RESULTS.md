# 冻结 LeJEPA 的非线性读出诊断

使用全部 16 份冻结 checkpoint、6 组控制，以及每个拟合读出对应的两个固定物理评价过程。CAL 和 VAL 各由独立平稳状态生成。训练时以 VAL 的逐轴或整体状态 MSE 选择读出，TEST 的真值评分仅用于诊断。模型、校准预算和数据流在运行前封存。独立 TEST 未参与拟合或选择。本轮保存了参数与逐窗口评分，可从权重重放。

本表每组用与其训练条件速率相同的独立 TEST。原来明显降低线性可读出性的六个 checkpoint 中，四个经 MLP 后最快因素 R² 达 .899–.995，且慢集准确率均提高。在两个 seed 7811 checkpoint 上，MLP 只能部分恢复最快因素。两者都可线性读出最慢轴二阶 Hermite 模式，R² 分别约 .660 与 .715。低线性 R² 与高二阶 Hermite R² 可以同可逆或部分可逆的非线性编码共存。

seed 7811 在两种谱交错 TEST 中，MLP 相对三阶读出降低了状态增量误差与跨界最小间隔 MAE，准确率却下降 4.30 和 3.61 个百分点。总体结果也取决于最快因素未入选的窗口。最快因素实际进入物理慢集的窗口中，准确率分别由 34.2% 和 40.4% 升至 66.4% 和 74.8%。总体准确率同时受其余窗口新增错误影响。

## 控制与复核

- 解析三阶剪切的第一轴在同速率宽间隔 TEST 中由线性 R² .793 提升到三阶近 1，慢集由 78.8% 升至 95.5%。物理目标分母固定为 1，读出采用有限独立参考方差，这允许近乎精确的逐状态读出仍有少量排序错选。
- 原可逆观测在同一 TEST 的前三轴线性 R² 为 .912/.764/.928，MLP 为 .993/.999/.999，慢集由 67.7% 升至 93.8%。
- 真缺轴控制在任一种测试读出下的最快轴 R² 约为零或更低。有限样本拟合可能给缺轴产生微小非零方差，诊断分数可计算，含义受缺轴限制。解析常量第四轴触发全窗口拒答。
- 从保存参数精确重放了 135,168 个窗口×读出评分（含重复使用的物理轨迹），统计及逐窗口预测均与初始封存产物相符。
