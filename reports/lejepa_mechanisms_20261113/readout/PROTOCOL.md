# 模块 B · 冻结 LeJEPA 的非线性读出诊断

冻结原四因素 Gaussian AR 实验的 16 个 LeJEPA checkpoint。研究问题是：先前失去最快因素线性可读出性的 checkpoint 中，因素是否仍能被非线性读出，以及该恢复是否改善命名慢集。把解码本身、逐窗口物理排序和二阶 Hermite 的线性可读性分别报告。所有读出使用物理真值标注校准，属于机制诊断。

同一个 master 2026111302 通过独立角色产生 CAL 8,192 个平稳 iid 状态、VAL 4,096 个 iid 状态、REF 32,768 个 iid 状态及 TEST 1,024 条新平稳轨迹。每条轨迹 193 个状态。TEST 的初始状态和基础创新按行配对用于四个速率配置，CAL、VAL、REF 在四个配置中分别共享，四个模型种子使用相同评价数据。每个冻结 checkpoint 的两个评价过程属于相同总体间隔组。一个过程的最快因子按谱分离条件生成，另一个按谱交错条件生成。两者复用完全相同的读出参数和参考分母。这让两个训练条件在同一物理评价过程上直接比较。总计 32 个冻结模型×评价过程的成对输出，训练种子和共享 TEST 轨迹均不能算作独立实验重复。

三个物理读出训练使用完全相同的 CAL/VAL 标签。所有输入及多项式特征的均值和尺度仅在 CAL 估计。线性 ridge、三阶总次数多项式 ridge 均使用相同的三项惩罚参数，按每个输出的 VAL 均方误差分别选择。MLP 两隐藏层各 128 个单元，SiLU，AdamW 学习率 .001、weight decay .0001、batch 256、3,000 更新。每 250 步记录同一 VAL 物理四轴平均 MSE，选最小者，平手保留最早 checkpoint。所有模型和控制共享独立于数据流的初始化与随机 minibatch 种子。测试不参与选择。另拟合一个独立的线性 ridge 读出，评估最慢轴的归一化二阶 Hermite 分量；该标签不参与任何物理读出训练。

正对照包括原可逆非线性观测和解析三角剪切 $x_1=z_1+0.2z_2^3$（其余轴原样）。剪切的精确逆属于三阶多项式类。负对照为 $[z_1,z_2,z_3,(z_1^2-1)/\sqrt 2]$，其输入与最快因素独立。每个总体间隔组运行同一组控制，所有读出使用和冻结模型相同的标签预算。有限样本拟合的负对照可能产生数值非零的参考方差，故另外明确测试有常量第四轴的解析负对照。真实零方差时四轴 slow score 不定义，整批拒答。若非线性读出未恢复最快轴，只能判定本预算和读出类未找到恢复。

按每个模型、每个评价过程、每个物理轴报告 TEST 状态 $R^2$、增量 MSE、平方增量分子误差、归一化慢度误差、跨真集合边界的带符号最小间隔误差、命名 top-2 准确率和非线性相对线性的修复/新增错选。估计分母取每个读出的独立 REF 坐标方差。物理目标固定总体方差 1，lag 4、16、32 等权。记录最快轴实际入选的窗口及其准确率。跨轴 `physical_cross_boundary_margin_mae` 计算真实入选集合外的最小估计慢度与集合内的最大估计慢度之差，再与物理间隔比较。逐窗口原始分数与拟合参数随结果保存。
