# LeJEPA 慢集机制实验的独立审计

日期 2026-11-13。审计依据为上一轮的[训练协议](../lejepa_slow_rank_20261112/training/PROTOCOL.md)、[前瞻协议](../lejepa_slow_rank_20261112/prospective/PROTOCOL.md)和[揭盲后误差定位](../lejepa_slow_rank_20261112/prospective/POINT_LOCALIZATION.md)。本文件说明执行前的核对项。结果审计另记时间及实际产物。

## 共同目标与数据边界

窗口物理分数采用 lag 4、16、32 的平方增量均值除以总体物理方差 $V_j=1$，以最低两个命名轴为答案。固定四个物理条件及各四个现有 checkpoint。模型和随机流的来源在运行前封存。两模块评估的是同一类冻结模型的不同误差来源。

- 新 CAL、VAL、REF、锚点和 TEST 按角色独立生成，检查与 11 月 12 日训练、前瞻和复验的随机命名空间无重叠。用整条轨迹拆分。每项比较的各处理共用窗口和物理目标。各模块若重用对方数据，只可使用同角色的数据，并需在协议中记录。
- 生成器可在内部用物理状态渲染观测。模块 A 的预测只取得观察数据和带轴名、剂量的查询，不能访问物理值、真实排名、隐藏轨迹、真值方差匹配或分数。模块 B 的标签仅按协议用于 CAL 拟合和 VAL 选择，TEST 标签保持在评分侧。
- 在揭盲前锁定协议、checkpoint、代码及来源、预测和模型选择。评分核对封存哈希、样本编号和对应窗口。若单进程计算，输出日志及保存顺序应能说明预测阶段未读取 TEST 真值；独立评分进程可进一步强化记录。对已有模型重放，保留源文件和权重身份。

## A · 无标签估计与命名、参考预算

固定相同的 checkpoint 和新评价窗口，交叉 CAL 128/1024 条轨迹、每轴 16/256 个命名扰动基点、128 条参考轨迹/32,768 个 iid 平稳参考状态。以八格完整结果为主，按预设成对差或完整因子边际差报告，保留各条件以及交互。

1. **CAL 和命名嵌套。** 每个 bank 只生成一组 1024 CAL 和 256 基点，小预算取前缀。所有组合使用同一 CAL 和锚点流。锚点的正负扰动和四个方向按基点配对，剂量不变。不能将低预算的独立重抽与扩容效果混合。
2. **参考是采样设计对照。** 两档同时改变行数与自相关结构，应解释成“替换参考设计”的效果。如果要进一步识别纯样本量效果，另预先固定同采样设计的嵌套对照，例如 iid 参考的等行数子样本。每个组合的参考方差须与它的动态分子来自同一坐标、同一命名排列，且保持物理答案 $V_j=1$。
3. **命名随基改变。** CAL 增量会改变白化、谱基及后续最优排列，同时改变按该基计算的分母。这个对照测量扩大 CAL 对端到端点读出的影响。只有在独立命名接口、有效的基匹配等额外条件下，才可谈去掉命名路径后的基误差。报告滞后特征值间隔、匹配第一名与第二名的目标差、同坐标参考分母变化。不同谱基的相同排列下标未必代表同一个轴，轴一致性诊断须考虑方向连续性、置换与符号。
4. **终点。** 先报逐窗口命名 top-2 错误和成对救回/新引入数，并报告真实第 2、3 名物理轴之间的有符号预测间隔误差。固定分层边界后才按真实 gap 诊断。保留校准大小与命名大小的交互，避免将整体均值改善外推到谱交错且窄间隔条件。物理标签给出的排列、完美基或方差替换属于评分后的 Oracle 诊断；结果无法直接产生可观测作答保证。

## B · 受控标签预算下的可读出性

固定同一批冻结 checkpoint。同一 checkpoint 的线性、三次多项式和小 MLP 读出使用相同的物理标签 CAL/VAL 配额、相同 REF/TEST 及轴目标。只训练诊断探针，报告优化成本和模型规模。将“多读出能力是否能救快轴与慢集”和“只拟合原生坐标能否可靠排序”保持为两个问题。

1. **公平读出。** 标准化及多项式列缩放参数仅由 CAL 得到。所有探针选择规则预先固定。若用 VAL 选 MLP 的 checkpoint 或正则强度，应按固定的状态重建损失，或明确区分另立的动态损失实验。TEST 不用于选超参、探针 seed 或报告窗口。若有 MLP 多初始化，保留种子结果及选择方式。多项式展开的交互项、正则化、秩和条件数可帮助排除求解失败。
2. **参考分母和动态误差。** 在独立 REF 上经过同一已冻结探针后求每个预测坐标的参考方差。所有组合物理真值统一用 1。状态 $R^2$ 分轴报告，同时报告真实第 2、3 名轴之间的有符号间隔误差、top-2 及快轴进入慢集的子组。状态恢复改善与增量恢复、排序改善可分离。若补做真分子、真方差替换，标作 Oracle 诊断。
3. **正负控。** 正控使用可逆非线性且已知逆落在测试读出类中的观测，例如三角三次剪切，对照揭示探针在同样标签量下的灵敏度。负控应确保删去的轴独立于所保留轴。若构造预测坐标精确常数，归一化分数无定义，应显式标记缺轴和四轴评分不可用，或按预登记规则把其分数设为 正无穷 作为三轴基线。有限训练可能拟合偶然相关，得到很小的非零方差；分数对仿射尺度不变，此时不能把四轴表面可算当成缺轴被恢复，应该同步核对 R² 与预测方差。
4. **解释门槛。** 非线性读出在独立 TEST 同时恢复被削弱的快轴与慢集，比单独提高任一指标更支持非线性纠缠参与失效。线性和两类非线性探针都失败时，只支持“本实验读出类与标签预算下恢复困难”。正负控不能把未观察到恢复改写为信息论证明。

## 统计单元与结论范围

- 同一评价窗口在八个处理或多个探针间共享，使用配对差。若一份参考或命名面板供应多条窗口，以独立 bank 及其全部窗口作重抽样单位。固定 bank 条件下的逐窗口统计须明确目标范围。若按四种子配对、在各物理条件重用训练 seed，模型层比较按 seed 处理配对，不能把 16 个 checkpoint 当成 16 个独立同分布训练重复。条件化到现有 16 个 checkpoint 的区间不能直接外推到重新训练。
- 主结论分别陈述 A 的估计环节效应和 B 的读出上限。干预了冻结表示的处理流程，可比较点预测改善。训练为何产生某种误差需要另做受控训练干预，并在共同物理过程和相同评价窗口上配对检验。本轮比较不会单独确立训练因果机制。
