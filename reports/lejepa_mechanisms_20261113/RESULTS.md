# LeJEPA 慢因素可靠选取的本机机制研究

2026-11-13。本轮完成了两个预先固定设计的机制实验、冻结读出的独立复验和误差定位。主要结论是：**轴估计误差与非线性读出不足是两条不同的失效路径；谱交错条件下观察到的低线性可恢复性，有一部分能由非线性读出恢复，并转化为慢集准确率收益。** 参考估计和窗口抽样仍会改变相近读出的排序表现。本轮没有建立一般的信息丢失结论或无真值可靠性证书。

## 完成范围与数据口径

- 沿用上一轮 16 个末步 LeJEPA checkpoint，四个动力学条件各四个配对训练初始化。未重新训练、缩减或修改这些编码器。原模型本来就是四因素 Gaussian AR 的受控 MLP 配置，本轮不把它等同于完整视觉 LeJEPA。
- 主指标为每个窗口 lag 4/16/32 的等权平方增量除以总体物理方差 1，选最低的两个命名物理因素。实际读出采用自身预测坐标的独立参考方差。所有比较固定物理答案。
- 模块 A 完成 64 套独立校准银行、16,384 条新窗口的八臂配对实验，先封预测再单独揭盲。
- 模块 B 让线性、三次多项式和两层 128 宽 MLP 使用相同 8,192 个 CAL 标签和 4,096 个 VAL 标签；另有可逆观测、解析三次剪切和缺轴控制。每个拟合读出交叉评价两个物理过程，每过程 1,024 个窗口、每窗口 193 状态，参考为 32,768 个 iid 状态。初轮为代码预锁的新留出诊断，TEST 不进入拟合和选择；随后全部已拟合读出在另一套 REF/TEST 上进行了严格预测封存后的独立复验。
- 本机实际内存 24 GiB，10 个逻辑 CPU，当前 MPS 不可用，使用单线程 Torch CPU。当前 Torch 2.15.0 / NumPy 2.5.4 与历史 2.14.0 / 2.5.3 有差异。只读重放全部 16 模型后，历史命名排列与 top-2 计数精确一致，最大数值统计差为 3.25e-7。模型、源码、协议及预测均保留散列。见 [环境重放](ENVIRONMENT_REPLAY.json)。

模块 A 使用无标签动态校准和命名扰动，模块 B 使用稠密物理标签。两模块的信息条件不同，跨模块准确率不作为同信息条件的算法优劣比较。

## 1. 增加解混校准的收益由表示条件决定

CAL 使用同池 128/1024 条轨迹前缀；命名使用同池 16/256 个扰动基点；参考对比为 128 条轨迹与 32,768 个 iid 状态。八个组合共用同一评价窗口。

| 条件 | 扩大 CAL 的平均准确率收益 | 固定 checkpoint 的银行重抽样 95% 区间 |
|---|---:|---:|
| 谱分离、宽间隔 | +6.21 个百分点 | [3.23, 9.55] |
| 谱交错、宽间隔 | +3.14 个百分点 | [1.53, 4.97] |
| 谱分离、窄间隔 | +14.07 个百分点 | [8.36, 20.17] |
| 谱交错、窄间隔 | +2.81 个百分点 | [−0.35, 5.38] |

预先指定的窄间隔组差中差为 **11.27 个百分点，95% 区间 [4.70, 18.05]**，四个配对训练种子均为正，满足预定复现判据。区间刻画固定这些模型后重新抽取校准与评价银行的波动，不能读成对所有重新训练模型的保证。

机制诊断与收益方向一致。在谱分离窄间隔组，物理轴 2、3 的非命名线性成分方差占比中位数从约 25.2%、23.6% 降至 6.41%、6.81%。全部低预算到全部高预算，真实第 2/3 名比较的符号翻转由 1183 降至 787，准确率由 60.77% 升至 75.76%。这些中间量支持有限校准造成的串轴误差参与错选。CAL 干预同时改变谱基、命名次序和同坐标分母，尚未分离每条中介路径的独立贡献。

NAME 16→256 在全部 128 个 CAL×银行组合中未改变任何匹配，因此本实验没有观察到扩大命名预算的收益。这不证明原匹配全部正确。参考设计的平均收益为 0.42–1.57 个百分点，且它同时改变数量与自相关结构，不能解释为纯样本数效应。见 [模块 A 完整报告](factorial/RESULTS.md)。

## 2. 一部分“线性读不出”的因素仍保留在表示中

初轮中，原先线性恢复较弱的六个谱交错 checkpoint，有四个在 MLP 下恢复了较高的最快轴 R2。随后预先固定这四个模型作为复验关注对象，同时保留全部模型。

独立复验中，这四个 checkpoint 在各自两个固定评价过程下均达到最快轴 **R2≥.85**，实际范围 **.901–.995**，且 MLP 的慢集准确率均高于线性。四个 checkpoint 来自两个初始化、各自两个间隔条件，八项评价不是八次独立训练重复。其余两个弱恢复 checkpoint 的最快轴 R2 仍只有约 .16–.30。

在全部 16 checkpoint×两个评价过程的 32 项比较中，三次多项式和 MLP 均提高了相对线性的慢集准确率。它们使用物理 CAL/VAL 标签，说明信息可被这种诊断读出利用，不代表实际无标签校准已有同等能力。

因此，实际训练中的“最快轴线性 R2 降低，同时最慢轴二阶模态更容易读出”，不能直接解释成最快因素被完全删除。该信号至少可以与非线性编码后的可恢复信息共存。真缺轴控制在相同读出预算下的最快轴 R2 约为零或更低，解析常量输出明确触发分数未定义。见 [初轮读出诊断](readout/RESULTS.md) 与 [独立复验](readout/replication/RESULTS.md)。

## 3. 固定评价物理过程后，训练条件的影响仍存在

同一间隔组的两个训练条件，只改变最快轴的训练配对相关系数；原始训练共享初始化、噪声及预算。本轮让两种训练模型在完全相同的评价物理过程和每条轨迹上比较，读出拟合与参考不随评价过程改变。

以下为独立复验，四种子平均 top-2 准确率。

| 共同评价过程 | 谱分离训练：线性 → MLP | 谱交错训练：线性 → MLP |
|---|---:|---:|
| 谱分离、宽间隔 | 90.33% → 96.95% | 60.60% → 88.26% |
| 谱交错、宽间隔 | 91.21% → 97.22% | 66.72% → 91.31% |
| 谱分离、窄间隔 | 90.28% → 96.14% | 66.28% → 89.92% |
| 谱交错、窄间隔 | 91.11% → 96.75% | 72.19% → 91.82% |

这排除了“全部差距只是评价物理过程改变”的解释。非线性读出显著缩小差距，但各共同评价条件仍有约 4.93–8.69 个百分点的平均差异。当前比较识别特定配对训练条件改变后的总结果，不能单凭二阶模态与错误共同变化认定它是唯一原因。更多训练初始化和进一步的中介干预仍未完成。

## 4. 参考估计与两类错选的权衡会改变总体比较

初轮 seed 7811 的两个谱交错模型中，MLP 相对三次读出提高了最快轴 R2，却降低了总体准确率。**这一准确率下降未在独立复验中复现。** 新宽间隔过程中，R2 从 .101 升至 .166，准确率从 82.03% 升至 82.71%；新窄间隔过程中，R2 从 .161 升至 .301，准确率均为 82.03%。因此不把初轮下降写成稳定的实际模型结论。

揭盲后的定位显示，两轮都存在相同方向的子组权衡：MLP 在最快因素真实入选的窗口修复更多错误，但在它真实未入选的窗口引入额外错误。宽间隔初轮两子组的净正确数变化为 +47/−91，复验为 +38/−31；窄间隔相应为 +52/−89 与 +50/−50。总体变化由两者合成。

只交换已冻结读出的旧/新参考与旧/新窗口，宽间隔 MLP−三次正确数依次为 −44、−25、−17、+7，窄间隔为 −37、−12、−14、0，每格 1024 个窗口。两个数据来源的变化都参与了整体比较方向的改变。仅把最快轴分数替换为物理真分数后，初轮宽/窄差异从 −44/−37 变为 −6/+7，支持最快轴分数误差参与了这些具体错选；这是 Oracle 事后诊断。

解析三次剪切正控的读出几乎精确，仍有少量排名错误。以完全真实物理坐标配同一有限参考方差，能逐窗口复现该正控的选集；用总体方差 1 则按定义全部正确。这把该控制的残余错误定位到参考估计，而不是非线性逆映射失败。该控制不是所有方法的一般性能上限。见 [误差定位及参考交叉对照](diagnostics/RESULTS.md)。

## 研究判断与后续边界

本轮使两条机制具备更清楚的实证支持。

1. 在因素近线性可恢复的条件，有限解混校准会留下串轴误差；增加 CAL 能改变跨边界分数并修复选取，收益在本轮谱分离窄间隔组尤其明显。
2. 谱交错后，部分信息仍能由非线性读出恢复；只扩大现有线性谱解混的预算不能完全利用这些信息。评价可辨识性时必须注明允许的读出类，以及状态恢复、动态分数与最终选集分别表现如何。

本轮使用本机可完整完成的低维机制实验，没有降低封存后的样本量或优化预算以取得结果。缺少的研究包括读出类与标注预算的系统边界、非线性动态误差的可观测控制、更广的训练初始化和动力学、正式视觉观测与 H-JEPA 层级验证。后两类应另做算力评估和服务器阶段设计，不以缩小视觉/层级模型的结果代替目标实验。本轮未访问服务器。
