# 冻结 LeJEPA 解混、命名与参考设计的配对因子实验

复用前轮四种 Gaussian AR(1) 条件、四个配对训练种子的全部 16 个末步 checkpoint。没有训练。每个 checkpoint 生成四套彼此独立的校准、命名、参考与评价随机流，每套 256 条新轨迹，每条 193 个状态。总计 64 个独立银行、16,384 个评价窗口。各银行的八个实验臂共享同一批评价轨迹。跨条件及训练种子也使用不同的独立银行随机流。全部随机命名空间在评分前固定，且与前轮不同。

| 因子 | 低水平 | 高水平 |
|---|---|---|
| 解混校准 CAL | 128 条轨迹 | 1024 条轨迹 |
| 命名 NAME | 每轴 16 对正负扰动 | 每轴 256 对正负扰动 |
| 参考设计 REF | 128 条独立轨迹，每条 193 状态 | 32,768 个 iid 平稳状态 |

CAL 两档与命名两档分别共享同一池的前缀。两个参考设计使用独立随机流，比较同时涉及样本数和相关结构。沿用前轮校准白化与对称 lag-1 特征分解，命名剂量 ±0.15，使用冻结的响应排列匹配。每个 CAL/NAME 组合中，命名顺序和参考方差在同一坐标内计算。CAL 改变可能同时影响方向和命名。固定 CAL 时仅改 NAME，在同一组未命名轴上检验纯置换的作用。全部编码、拟合和预测在 CPU 完成，沿用原始四维编码、四轴目标和数据条件。

物理目标是 lag 4、16、32 的平方增量均值除以总体物理方差 1，输出最低的两个命名因素。真实并列时索引优先。提前保存每条预测的逐轴分子、分数、top-2，各银行和实验臂的未命名方向、物理命名排列、参考方差与 lag 特征值。预测不读取目标分数。封存预测后独立重放评价随机流并计算物理分数。

主判据取准确率的 CAL 高减低，均匀平均 NAME×REF 四种组合，然后用分离窄间隔减谱交错窄间隔。报告点估计、四个配对训练种子的差异以及条件于 16 个固定 checkpoint 的银行重抽样区间。复现判据为差异点估计为正、95% 百分位区间下限大于零，并且至少 3/4 配对训练种子同号。重抽样在各 condition×seed 内独立抽取整银行，保持银行内实验臂及窗口配对。区间描述固定 checkpoint 下校准及评价流程的重复变动，训练种子只有四个。

辅助对比包括 CAL 在每组 NAME×REF 下的简单效应，三项主效应、三项二阶交互和一项三阶交互。效应均用百分点，交互取差中差。对每个条件、种子与银行保存全部臂准确率及相对最低水平臂的净修复、修复、新损害计数。另报真实边界间隔 ≤.01、(.01,.03]、>.03 各层的结果，物理第 2、3 名在预测分数下的符号翻转与间隔 MAE。

事后诊断使用评价物理状态。对每个命名读出拟合物理轴的多元线性回归，报告非命名轴线性方差占比、残差方差占比、命名斜率以及用斜率换算的参考方差相对误差。固定 CAL/REF 改命名时，额外记录排列变化率及选集变化率。各银行和实验臂同时保存最佳与次优命名排列的归一化目标差。真实分子或分母的替换仅用于归因，评分前固定其算法：用物理命名轴的线性斜率平方把现有动态分子和分母换算到物理单位，然后分别将物理分子、总体参考方差 1 代入。若斜率不稳定，替换仅能说明当前坐标匹配下的诊断结果。无事后改臂、阈值或数据量。
