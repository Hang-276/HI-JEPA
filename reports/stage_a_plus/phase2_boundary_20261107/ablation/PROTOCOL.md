# 已归档 JSON 的 TRAIN 残差交叉均值消融

本协议在本次运算前写入。它是看到 Phase 1 结果后提出的**事后开发诊断**，不能恢复 CAL 的独立性。只读取 Phase 1 的四份 freeze 与四份 reveal JSON；不读取数组、权重、TEST/FINAL，不拟合、不采样、不训练。

唯一新增操作：对每个已冻结父模型，将 `cal.train_residual_cross` 的三个时距等权均值记为 U_T；分别将同一个 U_T 加到原 `b_current` 和原 `b_fixed` 的四轴分数上。新方法命名为 `b_current_plus_train_cross` 与 `b_fixed_plus_train_cross`。没有系数、阈值、分工况估计或可选变体。旧规则原样报告，原 Fine 选集、TRAIN 规范、三个时距及所有匹配不变。缺失预测继续缺失。

主比较是修正后的 current 对修正后的 fixed 和 identity/size/direction。相同可评价覆盖下，current 须检出严格更多错例，且误报不多于每个对照；同时在至少两个实例的相近精度成败配对中，其按轨迹等权的 concordance 须严格超过 fixed 和三旧规则最大值。TRAIN 四轴 R² 最大差 ≤.01 为主分析，额外 CAL R² 匹配仅为事后分层。匹配对裕量差绝对值 ≤1e-12 记半分并列。方法物理 top-2 或真实/Fine top-2 在边界精确并列时分类拒判，单列覆盖。全部配对保留；实例→轨迹→配对等权，不把 8 对当 8 条独立轨迹。

修正后的逐轴余项为 `(当前真实残差交叉项 − U_T) + 残差能量漂移`。用已保存的真实分解检查恒等关系，绝对容差 1e-10。对原 Fine 错例、新规则的误报/漏报以及新规则排错/并列的成败对，报告全部四项固定选集跨界间隔及上述分解，不另挑最有利因素对。该分解使用物理标签，只作事后归因。

若新规则仍未通过门槛，停止此消融，不追加修正。即使通过，也仅登记为值得独立确认的开发候选。原 Phase 1 失败结论保留。本脚本先执行 freeze 产生方法锁，再单独执行 score；方法锁固定协议、代码与八份输入的散列，禁止覆盖已有锁或结果。
