# 事后拒绝解尺度审计结果

结论：原raw64的自洽拒绝伴随较大的参考尺度误差，但不能被解释成尺度完全不可用。Fine64确有更小的尺度误差；原报警收益幅度同时受到raw整体回退的影响。本诊断不改变主门失败，也不产生新的报警性能结论。

## 范围与重放核验

这是主试验揭盲后提出的机制诊断。只重放原16组参考面板的原64锚点查询，未追加样本或查询信息，未读取或重新评分评价窗口。所有原公开receipt、锚点排列哈希、查询分支哈希、编码标准差、图诊断完全一致。原图源码、.02门槛及返回值均未修改。

通过只读trace取出图求解器返回时已算出的solution标准差。16组Fine64捕获尺度与原接受返回值及FORECAST逐位一致；16组raw64仍按原规则拒绝，且四轴求解均已收敛。先封存REPLAY，再由score核对原参考物理标准差；该标准差与原SUMMARY逐位一致。重放耗时22.64秒。独立审阅者local_gap_audit检查trace与数据边界，未发现需修改问题。

## 尺度精度

相对误差定义为 `estimated_sd / physical_reference_sd − 1`；MAE在16组×4轴上平均绝对值，最大值取这64项的最大绝对值。这里只评价原参考面板的经验尺度。

| 解 | 原规则状态 | 相对MAE | 最大相对误差 |
|---|---|---:|---:|
| Fine64 | 16组接受 | 0.38957% | 1.33749% |
| raw64拒绝前的解 | 16组拒绝 | 1.21250% | 3.26513% |
| Fine-all已保存尺度 | 16组接受 | 0.01295% | 0.03523% |
| raw-all已保存尺度 | 16组接受 | 0.05580% | 0.12368% |

16/16组的Fine64尺度MAE均小于raw64拒绝前解。raw64整体MAE约为Fine64的3.11倍。该比较为事后描述，不新增显著性检验，也不等价于慢因素排序优势。

## 能说明与不能说明的事

- Fine64的尺度优势有直接的原参考真值误差支持，并非完全由是否通过gate制造。
- raw64边残差为2.520%—3.035%，超过原2%阈值；其全局尺度MAE为1.213%，最大轴误差为3.265%。边自洽误差与全局尺度误差是不同量，拒绝标记不能直接当作尺度质量的定量证书。
- 原Fine64对raw64的报警差比较了“接受图尺度”与“固定affine回退”。本诊断没有计算若使用raw拒绝解会产生哪些报警，因此不能将原37.82个百分点增益全部归因于尺度精度，也不能量化gate贡献了多少。
- Fine64相对Fine-all的保留门仍失败，原95%区间下端−7.93个百分点低于−5个百分点阈值；本诊断不更改去留规则、不调整门槛、不选择新预算。
- 一般尺度误差上界、未查询Jacobian误差控制，以及从尺度误差到具体排序错误的保证仍未建立。
