# 查询预算试验的独立代码边界审计

2026-11-11，theory_redteam。审查 `run.py`、`node_query.py`、`sparse_worker.py`、协议及其冻结依赖；没有读取本轮真实轨迹、运行正式实验或揭示标签。当前结论：**未发现阻止冻结和工程试跑的边界或统计配对错误**。这不是研究收益或有限样本覆盖率的验证。

## 信息访问与查询方向

- `fit_reference` 按同一随机排列的前缀生成1/64/512/all锚点；每预算先调用受限adapter，再将同一plus/minus交给Fine/raw。两个表征共享实际节点和物理查询，分别使用自己的可见坐标做最近邻，符合协议。
- adapter内部重放物理状态只为公开基线校验和指定节点的±dose观测生成。`physical.reshape(-1,4)[ids,None,:]` 与worker中 `z.reshape(-1,4)` 的节点次序一致；adapter只返回请求节点的可见分支及审计，不返回物理水平值。
- 每次独立worker进程只收到 `z`、当前预算的 `anchor_jacobian`、`anchor_ids`，没有未查询Jacobian字段。虽然总实验还会执行更大预算，较小预算预测不从其响应读值。
- 响应矩阵的行是命名物理干预轴、列是affine表征轴。`((plus_y-minus_y) @ beta)/(2*dose)` 与冻结图中右乘逆Jacobian的行向量约定一致。
- full预算按 `assigned[ids]=responses` 直接还原，绕过最近邻，能处理随机排列；稀疏分支保留被查询节点自己的响应，避免重复可见坐标的tie覆盖实际查询。
- `run.py`的物理水平值读取只发生在`score`；forecast只使用公开观测、历史冻结映射和命名扰动接口。每组truth使用自己的独立参考面板经验物理标准差，所有预算共享这一目标。

## 分子、比较对象及回退

`old.evaluate(..., affine_ref_sd=ones)`计算未标准化的局部积分慢度分子，再逐轴除以各预算参考标准差平方。固定标准差除法与增量平方平均可交换，因此与逐预算重新调用原评分器等价。工程试跑另包含直接重算的代数检查。

Fine与raw的所有间隔都使用原生Fine选集；raw不改成评价自己的选集。候选24条、报警6条及ID同分规则一致。

审计发现原协议未充分区分两种失败，作者已在冻结前补明，算法未变：

1. **参考图失败**：整条规则回退原固定affine分数；该预算仍计已付查询，不追加查询。
2. **评价局部响应unsafe且图成功**：原分子实现退成未积分affine分子，仍配该预算图分母；不是完整固定affine规则。局部安全数与图失败数分别报告。

两表征的full图均需16组全通过（失败比例≤5%在16组下即零次失败），局部安全数各至少95%。稀疏臂失败可触发预定回退，因此主比较的对象是包含回退的完整规则。

## 主比较和不确定性

- 16组分别使用独立reference、evaluation和锚点排列种子。bootstrap索引直接采样组，统一复用到所有预算与表征，保留参考不确定性和配对关系。
- 召回差为配对命中差之和除以共同候选错例数；每次bootstrap的分母也按同一组索引重算，没有把共享参考下的窗口当独立重复。
- 主门只用预算64：Fine64对raw64的点增益≥.05且区间下端>0，同时Fine64对Fine-all区间下端>−.05。1和512仅为解释。支持量与工程门先于通过判断，符合协议。
- 4096次整组percentile bootstrap是本试验的经验区间，**不是精确有限样本置信保证**。16个独立组决定有效独立重复规模。

## 成本与证据边界

作者已补明每规则可见信息预算与整实验实际调用量的区别。每组全预算单规则185,280分支；实现逐臂重复重放后实际189,896分支，正式16组3,038,336分支。Fine/raw共用物理分支，不再乘2；已有CAL、轴对应和训练成本不在这些新增查询数中。SUMMARY的`query_cost_per_panel`是每规则信息预算，完整执行量须按协议单列，不宜把两者混用。

稀疏worker的奇异值、条件数和图残差都检查**已查询并复用后的响应场**，不能证明未查询真Jacobian也满足门槛。最近锚点距离和自洽残差不提供隐含插值误差上界。通过主门至多支持冻结接口和生成器下的参考查询效率优势；不构成一般非线性可辨识性保证。

## 已执行的工程证据

`sparse_worker.self_check()`本身已包含非恒定、良态Jacobian加反向节点ID排列的full等价检查，并非仅在临时命令中测试。还包含单锚点恒定Jacobian仿射恢复与非法ID拒绝检查。作者保存的`WORKER_SELF_CHECK.json`与本审计者运行相同检查的输出一致：full精确等价；单锚点与密集结果精确一致；仿射标准差最大误差9.391598609909124e−12；边相对RMS为2.5813046184970515e−10。当前三个Python源码已通过AST解析。

一个非阻塞接口加固点：`node_query`在验证前将ID转成int64，会对外部浮点ID截断；正式调用来自int64随机排列，不受影响。worker已经拒绝非整数ID。此项不影响已冻结设计的访问边界。
