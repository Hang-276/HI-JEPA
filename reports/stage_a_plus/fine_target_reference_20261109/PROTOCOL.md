# 在目标工况尺度下重做动力学匹配检验

冻结源尺度的 OOD 实验几乎消除了近边界。揭盲后的物理读数表明，使用目标状态尺度可恢复近边界，但这改变了评价目标。本轮用新的参考面板与评价轨迹，锁定目标分布上的慢集定义，再重复两个 OOD 方向。 [尺度诊断](../fine_calibration_shift_20261109/RESULTS.md)

- 保留两个冻结 FHN 编码器的各自观测混合与历史轴命名，评价仅在对侧 ε，即 .08→.5 与 .5→.08。保持上一轮的物理配对生成器、同一个源漂移及等变读出。每个编码器额外用 256 条独立目标轨迹作为**参考面板**，与校准和评价均隔离。可见根分别为 2026124000、2026124001。预测只读该面板的 raw、Fine、动作和工况中的观测字段，用它估计 raw/Fine 的目标状态协方差。评分阶段在公开摘要一致后才读取该参考面板的物理标准差。
- 同槽所有规则都按同一参考面板、同一目标支持归一化。对原 Fine 用参考协方差的坐标方差。对每个解混用其行在该参考协方差下的方差。raw 也用相同参考轨迹。物理目标按参考面板真值的各轴方差归一化，所有规则用同样时距 4、16、32。评价轨迹自身不参与尺度估计。
- 各槽 64 个独立校准–评价组。每组源、目标各 96 条无标签校准轨迹，两臂共享生成器初始、动作、工况及高斯随机数。目标评价另有 128 条。可见根取 2026125000 + 1000×槽索引 + 2×组号作为校准，下一整数作为评价。与参考面板独立。用历史漂移分别估计同动力学与异动力学 Fine 方向，另报告同动力学下重新拟合组 0 漂移、raw 同规则和原 Fine。
- 主比较沿用上一轮两个 OOD 方向的同动力学校准对异动力学校准。任意物理近边界≤.05 的点命中增益至少 3 个百分点，等量预警检出至少 10 个百分点。四项单侧 98.75% 组重采样下界为正，预警误报上界低于 5%。每 128 条评价轨迹各发 6 个警报。用 4,096 次整组重采样，种子与上一轮相同的统计随机根和逻辑。若某类样本支持缺失，相关门失败并记不可判定。结果条件于锁定的独立参考面板。
- 预测先封存，不按观察到的结果选择参考尺度。评分阶段先读参考真值，再独立重放评价真值并核对公开摘要。前一轮结果保持原口径。只使用 MacBook 单线程 CPU 与冻结前向。
