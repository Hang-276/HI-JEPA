# 目标尺度下的动力学校准复验

**恢复近边界样本以后，两个 OOD 方向中，用源工况漂移直接估计目标方差方向均变差。重拟目标漂移明显修复，且超过原 Fine，但与错配方向的比较仍依实例而异。** 同槽所有方法使用同一个独立目标参考面板。评价物理尺度在封存预测后由该面板的物理状态算出。这里检验目标标准化的慢集，原源尺度结果保持单列。

以相同历史源漂移比较，目标方向相对源方向的近边界差为 **−12.33、−22.44 个百分点**，等量警报检出差为 −8.59、−20.08。两项主增益均失败。这次有 1,338 和 2,103 条近边界，足以区别这个失败与上一轮源尺度的支持不足。

把漂移改在同一目标校准的组 0 拟合，目标方向近边界相对保留历史源漂移提升 **14.57、20.11 个百分点**，等警报量检出提升 **15.81、16.73 个百分点**，两槽均有正的组差值下界。两个联合适配相对原 Fine 的点估计方向为正。相对使用历史源漂移的源方向，第一槽联合适配稍好，第二槽稍差。这个对照还没有平衡源与目标重新拟合的轨迹身份和工况。不能把修复完全归给目标工况匹配。下一轮将两种漂移在各自的新校准折上以同样预算拟合，再交叉应用于源与目标的方差方向估计。
