# 图参考尺度方法的适用范围与执行前审查

代码审查日期：2026-11-11，正式样本生成前。

`reference_graph.py` 的行向量约定一致：`dphysical @ J = dz`，因此边估计采用 `dz @ mean(Jinverse)`。同一个非对称可逆 affine 映射下，梯形边增量精确，连通图最小二乘恢复节点坐标至公共平移，方差不受该平移影响。模块的确定性 affine 自检覆盖了方向、平移与尺度恢复。

对非线性映射，需要区分数值算法可执行和它何时足够准确：

- 每节点 Jacobian 可逆是局部条件；全局可逆性以及两节点间插值路径上存在同一逆映射还需要额外结构。
- 端点 Jacobian 的梯形近似需要沿连接路径的导数变化可控；有限端点观测本身无法上界这段变化。较长的图边、稀疏尾部和参考节点间空白区域都可能增加偏差。
- 剂量有限、编码有限精度也会影响 Jacobian；本轮用预定条件数阈值约束数值稳定性，但没有从观测中得到未知真实 Jacobian 误差的置信上界。

令 B 为有向图的 incidence matrix，X 为中心化物理节点坐标，估计边增量为 `D = BX + E`。连通图的中心化最小二乘解满足 `Xhat − X = L^+ B^T E`，其中 `L=B^T B`。因此有条件地可以用 `||Xhat−X||F ≤ ||E||F / sqrt(lambda2(L))` 控制节点误差，逐轴标准差误差不超过该轴中心化坐标误差的二范数除以 `sqrt(节点数)`。这表明参考尺度还受连通强度影响。

本轮可见边残差只测量 E 在图梯度空间之外的部分：若 `E=Bv`，边残差可为零，但恢复坐标仍带有 v。因此 `.02` 门槛是可见自洽筛查。真值参考尺度误差由封存预测后的独立评价揭示；主结论只覆盖已冻结的具体估计器、模型、工况和样本方案。

实现采用 `L + 11^T/M` 的正定算子固定均值，无需物理位置锚点；Jacobi 对角为 `degree + 1/M`，四轴独立 CG。构图只使用标准化 affine 坐标和原有时间邻接，K、边权和数值阈值在运行前固定。

Fine 和 raw 共享命名物理扰动、剂量、全部参考节点、评价候选、图规则及计算精度。已知的物理轴名和扰动单位是一种强可观测接口；本轮支持的贡献应表述为这类接口下的尺度修复或可靠性诊断，而非仅靠未干预数据自动消除所有不可辨识性。
