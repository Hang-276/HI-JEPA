# 用不成对边际校准检查 Fine 的度量误差

- 两个冻结 FHN seed0，在对侧 \(\varepsilon\) 评价，保持源观测混合。每槽 32 个新独立组，96 条目标校准、128 条目标评价，另有 256 条独立目标参考轨迹。参考根 2026154000 加槽索引。校准根 2026155000 + 1000×槽索引 + 2×组号，评价为下一整数。用目标校准组 0 拟合漂移，组 1–3 拟合仿射等变方向。
- 原 Fine 和仿射解混按同一目标参考支持标准化。每个候选方向的符号用组 1–3 中基准与四个已知正均值工况的残差均值差来锁定，沿候选解混行取期望为正的一侧。全样本的候选列在参考面板独立排序，形成经验 CDF。外推固定裁到端点，不按结果调节。
- **无标签版**把该经验秩映射到固定标准高斯分位，再除以参考输出标准差。预测先封存。**不成对物理边际参照**在封存后仅打开参考面板的物理状态，各轴独立排序丢弃样本配对；用分位把同一候选 CDF 映射到物理边际。它不拟合任何物理配对方向。先封存这套预测，之后才读取独立评价的物理状态。物理目标对所有规则使用同一参考真方差。两个分位方案共享已冻结的轴方向与符号。
- 主检验是物理边际参照相对仿射解混的任意近边界点命中，两槽分别要求 +3 个百分点、整组单侧 97.5% 差下界为正、全窗降幅小于 1 个百分点。无标签高斯方案及 6/128 等量预警作为辅助。另报告候选定向是否与评分后的物理相关符号一致，不在评价时重选符号。4,096 次整组重采样，种子 2026155901 加槽索引。只用 MacBook 单线程 CPU。
