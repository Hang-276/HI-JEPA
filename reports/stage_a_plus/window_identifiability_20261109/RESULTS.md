# 同一个观测模型里的逐窗口正负对照

两种 4D VAR 各在三个工况强度评价。每格 4,096 个独立面板，面板内共用同一条 192 步评价轨迹，比较是否另有 8,192 次可见校准转移。表中覆盖率是联合规则作出判断的窗口比例，错答数以全体窗口为分母。

| 动力学旋转频率 | 工况强度 | 仅评价窗口 | 加校准 | 覆盖变化 | 两档错答数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 11.25° | 无变化 | 51.12% | 51.12% | 0.00 pp | 0 / 0 |
| 11.25° | 弱 .12 | 51.00% | 52.44% | +1.44 pp | 2 / 2 |
| 11.25° | 强 .8 | 52.25% | 82.20% | +29.96 pp | 2 / 0 |
| 30° | 无变化 | 12.21% | 12.21% | 0.00 pp | 0 / 0 |
| 30° | 弱 .12 | 13.09% | 14.99% | +1.90 pp | 2 / 3 |
| 30° | 强 .8 | 14.43% | 66.65% | +52.22 pp | 2 / 1 |

两个无变化格的端点解释分别在 2,002/4,096（48.88%）和 3,596/4,096（87.79%）窗口给出不同慢集。联合规则用完整角度区间，无变化时加校准前后的输出逐条一致。两个强格的覆盖增益配对下界为 +24.34、+46.60 个百分点。所有联合规则的无条件错误作答率同时上界均低于 2.89%，低于冻结的 5% 验收门。三项主门均通过。

相同的角度区间和候选集下，联合规则比逐轴取区间多覆盖 0.24–1.73 个百分点。这个较小的增量对应保留四轴共享同一角度，远小于强工况额外校准的增量。弱工况的两档角区间中位宽仍为完整的 14°。该结果只说明当前有限样本规则多数时候没有缩小区间，不能将弱工况解释为与无工况变化同样的总体不可辨识。

本轮的主要增量是把总体固定选集改为逐窗口物理选集，在同一个公开模型中同时看到两类窗口。即使轴角度完全无法从观测确定，一些窗口的物理慢集仍为所有解释共有。另一些窗口在完全相同的观测下具有不同答案。有变化时，对同一目标只增加校准量可以解除一部分歧义。结果依赖已知观测漂移、命名平面与候选角度范围，属于受控模型中的可观测保证。 [冻结协议](PROTOCOL.md) · [证明](THEORY.md) · [封存顺序](FORECAST_RECEIPT.json) · [完整读数](SUMMARY.json)
