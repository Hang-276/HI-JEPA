# Round 3：现有物理矩下的单向混合边界

2026-11-04。执行范围在 [SHEAR_AUDIT_SCOPE.md](SHEAR_AUDIT_SCOPE.md) 中事先固定。只读取四个已有物理实例的 TRAIN/CAL，复用 Round 2 的 TRAIN 尺度和创新方差；没有读取 Fine 表示、加载模型、重新拟合或生成数据。全记录见 [JSON](SHEAR_BARRIER_AUDIT.json)，计算入口见 [脚本](shear_barrier_audit.py)。

## 1. 这项诊断回答什么

对每个指定单向混合 `v_i ← v_i + t v_j`，求出从原表示出发，声明的慢因素集合首次失去**严格唯一 top-k**的最小绝对参数及对应自由 Gaussian profile 风险。完整证明、切触 tie 和极限 tie 的区别见 [单向混合理论](SHEAR_BARRIER_REVIEW.md)。

评分的矩来自已存在的有限数组；风险函数使用同尺度下真实创新方差与均匀九 regime 的解析公式。因此这里把“有限数组的排序边界”和“数学仿射候选的总体自由 profile 风险”作配对诊断，**不是实际 Fine 的总体风险或高概率保证**。所有方向均保持物理轴命名，不重新匹配轴。

对全部12条单向混合取最小边界，只提供一般仿射类严格排序失效风险下确界的**上界**：已构造出这么低风险的失效候选。它不是安全下界，不能保证所有更低风险的一般仿射或非线性变换都正确。跨边界 tie 也不必等于原 G0 的 FP32、固定索引规则已经错选。

## 3. 算术核验与成本

每条方向使用完整 target/non-target 约束，不能只比较被混合的两轴。一般 TRAIN 协方差对角元按实测 FP64 数值保留；用80位 Decimal 对已计算的 binary64 二次多项式系数求根。这提高根计算精度，但不是输入矩的区间证明。

- 逐方向矩阵变换分数与有理式最大差：5.56×10⁻¹⁶。
- 首次临界点的最小目标 gap 绝对值最大：6.67×10⁻¹⁶。
- 全部有限边界内的正负两侧固定核验点保持严格排序；解析风险与矩阵 logdet 公式一致。
- 读取8个已有物理数组成员、两个已有 JSON；新拟合、神经前向/训练、随机采样、新物理数据、TEST/FINAL 数组读取及服务器/GPU操作均为0。

首次尝试使用系统 Python 时因未安装 NumPy 在导入阶段退出，尚未读取科学输入。随后使用已提供的 bundled Python 完成一次计算，没有安装依赖、改变环境或调整公式。输入、脚本和执行前范围文件均记录 SHA256。

这些检查确认解析边界的计算一致性；它们不证明实际 Fine 位于某条 shear 路径、不提供实际训练 excess，也不替代原逐轴恢复门或新的独立物理实例。
