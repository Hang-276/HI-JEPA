2026-11-05，第1—4步研究方案。**本轮结论：中心命题和可区分机制的验证协议已定；强理论新颖性门仍未通过。可以保留一次有明确范围的本机机制验证，不应据此认定强论文贡献已经成立。** 本轮没有启动实验，也没有扩展后验证书链。

## 1. 定下来的主张

研究在同一规范与动态评分规则下，因素辨识误差何时会破坏正确慢因素的选择。核心候选是：**相同辨识风险、相同轴误差大小和慢度间隔，仍可能因误差方向不同而产生不同可靠性。** 已有受限精确边界和合法动态反例提供支点；轴恢复与选集正确分别评价。

新颖性审查明确：Gaussian风险、方向导数、Rayleigh商残差和普通margin界都是经典背景。尚未找到完全相同的受控结论不等于首创。当前应定位为目标相关的条件机制研究；普遍理论、实际Fine证书和Fine必要性均不在已证贡献中。

## 3. 实验设计的关键改变

主要对照使用**同一系统、同一批轨迹、相同幅度的正负表示扰动**，保持风险、轴误差及数据不变，预测一侧选择错误而另一侧正确。另设同幅度慢块内旋转负控。跨系统“同F、同γ、不同χ”保留为补充，不用其有限样本噪声差作单一因果归因。

协议采用四维九regime合法生成器，补足自然参数rank8，并配置固定慢/快保护轴。主配置φ=80°、θ=±9°时，纸笔预测两侧都达到预声明轴精度，负角选{2,3}，正角选{1,3}。另外冻结一个单向剪切的次要预测，用同一批独立验证轨迹检查方向结论能否跨误差形式保留。均为**预先预测**，没有新实验测量。
