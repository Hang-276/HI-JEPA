# 被动数据中的公共上下文调整

在随机工况下，固定同一个过去状态和动作来比较 \(E[rr^\top\mid u]\) 可以避免把该样本中各工况抽到的状态不平衡当成方差方向。精确配对依赖模拟器。这里用被动数据拟合公共的残差二阶矩预测 \(H(c)\)，再用它减少有限样本差分的波动。若工况和过去状态及动作独立，固定 \(H\) 后 \(E[H(c)\mid u=j]-E[H(c)\mid u=0]=0\)。减去它在总体上保持原差分。有限面板能否改善是本轮问题。

- 固定两个 FHN seed0、对侧 \(\varepsilon\)、观测混合和 256 条独立目标标准化面板。每槽 32 组新实验，每组源/目标各 96 条校准，目标评价 128 条。两校准共享原随机底流。参考可见根 2026146000 加槽索引，校准根 2026147000 + 1000×槽索引 + 2×组号，评价为下一整数。各角色独立，所有预测先于标签封存。
- 原读出用源组 0 拟合漂移，再在目标组 1–3 估计方向。调整版保持这个源漂移，在目标组 0 用公开残差外积拟合一个五工况共用的 \(H(c)\)。特征用完整三次状态项与线性动作，附加源漂移预测的十个外积项。去掉常数列后按拟合折标准化，固定 ridge .001。估计方向时，将各工况经验差分减掉相应的 \(H\) 均值差。保持原未调整基准残差矩作白化，因此只改 D。不可用时回退原 Fine。错配对照沿用同一 \(H\)，把目标组 1–3 的整轨迹 \(H\) 路径循环平移一位，改变它与工况、残差的对应。正控在目标组 0 重拟漂移。各臂使用相同数据、相同目标尺度及读出。
- 冻结比较是调整版对源漂移版的任意近边界≤.05 点命中。两个 FHN 均需提高至少 3 个百分点，组单侧 97.5% 下界为正，且相对正控的提升至少恢复 30%。错配版若有同等提升，只能保留估计器变化。全窗六对慢度间隔 MAE 和每 128 条 6 个等量预警为辅助。各槽用 4,096 次完整组重采样，种子 2026147901 加槽索引。
- 校准折只用观测、动作、工况与冻结 Fine。标签只在评分阶段读取，重放并核对公开摘要。配对反事实、真值和旧评价数据均不用于拟合。仅 MacBook 单线程 CPU。
