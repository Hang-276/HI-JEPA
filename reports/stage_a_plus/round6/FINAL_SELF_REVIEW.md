## 1. 后验有限样本证明逐项核对

| 核对项 | 结论与限制 |
|---|---|
| 目标 measure | AΩ 是全审计 law 下未归一 restricted KL；bin 只划分 Ω，全样本 n 作分母 |
| 风险恒等式 | R−N+V 精确；q 可在 bin 内变化；减去 N、加上 V 的方向正确 |
| KL 与真实零概率 | log x≤x−1 给 KL≤χ²≤L2²/ε；真实 p 可以含 0，不要求 pmin |
| 噪声统计量 | f(v)=Σv−∥v∥²/Σv 在非负正交域为 2-Lipschitz（L1）；空 cell 按连续延拓为 0 |
| 集中界 | Brier 项处于 [0,2]，joint-cell 指示项处于 [0,1]；K项双尾与单尾风险失败概率正确合并 |
| 余项 | V≤L²h²μΩ/2 由独立副本方差恒等式给出；L 必须控制真实 p，不以 q 导数替代 |
| 最终上界 | 使用 R 上端、N 下端、V 上端；普适 cap 是 μ⁺log(1/ε)，不称小误差保证 |
| 自适应选择 | q/bins 独立固定或有统一覆盖；7 snapshot 选择不能被忽略；有限候选修正仅在候选本身合法时适用 |
| 有限样本非空 | 条件上可以成立；P8 给显式充分接受式，含经验量的 n 条件不称采样前承诺 |
| 当前小样本 | m=9、95%覆盖下，假想 n=24/32 的本构造退化为平凡 cap；只否定此构造，不否定其他统计方法 |
| 固定 context | 联合平均风险不能填固定 c；仅有随机 context 的 Markov 结论，且不能自动与其他门相交 |
| 尾部 | restricted KL 与 T7 接口一致；小尾概率不替代 head score 尾能量；不重复计入 π₀ |
| 完整 q 的信息 | 满秩 learned contrast 与可逆 Fine 给精确注入性；一般 constant-q 反例不否定该特例；分箱/量化不继承精确结论 |

固定检查包含 12 组：exact rational Brier/方差恒等式、空 cell 和 Ω 质量、102 个梯度点与1225个 L1 成对检查、含真实零概率的20个 KL 方向检查、粗校准反例、小样本退化、有限 n 的纯后验算术非空例、T6尺度及失败概率常数。它们是公式核对，不能从有限枚举证明一般定理；一般结论依靠正文推导。
