# 图像验证设计：从因素恢复到可靠慢排序

日期：2026-11-11。状态：**可审阅设计，尚未成为启动协议；已做四个固定状态的 CPU 图像接口自检，没有启动图像科学验证、训练、GPU 或远程任务。** 本文件汇集研究问题、对照与去留建议，最后一节纳入本轮跨冻结模型结果；它不是已登记的图像实验协议，也不改变既有 64 节点实验的失败判定。

## 1. GPU 应回答的一个问题

**主命题：在已获得命名因素方向、局部增量可较准确恢复的图像表示中，参考尺度错配仍能导致窗口慢集错误；保持增量估计不变，用可见查询恢复一致的参考尺度，能在独立窗口上减少这些错误。**

这是条件机制的外部验证。图像模型可能没有恢复因素，可能没有明显尺度偏差，也可能有偏差却不足以改变排序；这些都是预先允许的失败原因。任务不是保证每种图像表示都出现改善。主比较也不要求 learned 表示超过 raw；若同信息 raw 同样修复，则支持尺度机制，而 learned 表示独立优势仍未建立。

当前密集图修复支持上述机制；独立参考试验中，Fine64 相对 raw64 的收益门通过，但相对全查询的非劣门未通过。新图像试验不承担补救该门、证明省查询或证明无真值置信证书的任务。

## 3. 可控图像世界与目标

首个图像世界保留现有四因素 FHN 动态，观测替换为两个可分色的光滑 Gaussian 光斑。四个真实因素依次控制红光斑的横纵位置、绿光斑的横纵位置。图像为 64×64 RGB float32，光斑固定宽度 3 像素，中心映射为 `32 + 20 tanh(u_i / 4)`；蓝通道为固定背景。[最小渲染接口](image_renderer.py) 已实现这一公式。

四个固定状态的 [CPU 接口自检](IMAGE_INTERFACE_CHECK.json) 确认重复像素完全相同、单光斑通道隔离、图像与剂量分支形状正确，四个响应方向均满秩。条件数约为 1.00、2.24、1.00、101.34；最后一个状态含因素值 ±12，处于映射饱和边缘，超过旧低维读出的条件数 20 门。半剂量与全剂量中心差分的最大相对变化为 2.10×10^-4。这是接口工程证据；**四点满秩不等于真实 FHN 轨迹上的稳定可恢复，也不是排序收益。** 正式接入轨迹时仍须统计饱和与数值拒答比例。

渲染器不提供因素值、中心位置或解析逆给读出。查询接口只返回同一场景的四个命名因素各 `±0.0175` 改变后的图像，以及因素名称和剂量；其他因素保持不变。开始阶段不加入量化、遮挡、随机背景或噪声，先避免将信息丢失混入尺度问题。饱和区域、图像导数退化及剂量小于数值分辨率必须在接口自检中原样计数。

源训练工况暂定 ε=.5，评价为 ε=.08 与 ε=.5；前者为主工况，后者用于检查改善空间是否随工况改变。最终采用哪一方向，应由本轮低维复现的**预定分支判断**决定，并在图像数据产生前写死，不能看图像结果后换主工况。

每个独立参考面板的真实经验因素方差定义目标尺度。同面板评价窗口中，对每轴计算 4、16、32 步平方增量均值的等权平均，再除以该参考方差，选最小两轴。使用经验参考目标可以直接对应当前图修复；它不自动验证总体归一化定理。若另研究总体目标，必须另外加入参考采样误差，不能混用两个目标。

## 4. 统一信息与高维 raw 对照

所有表示共享原图、命名剂量响应、CAL、参考和评价轨迹；只有 CNN 使用无因素标签的 TRAIN 图像对训练。监督因素值只在全部预测封存后用于评分。轴名称来自主动查询，这本身是额外信息，论文应明确写出，不能称为纯被动视频下的自主可辨识。

主接口统一为四个命名读出。对原像素 `f_raw(I)` 和冻结 CNN `f_cnn(I)`，分别使用同一算法拟合矩阵 B，使 CAL 的可见特征变化满足 `Δf B ≈ Δu`。其中 `Δu` 只是查询返回的已知位移，不含因素水平值。所有后续控制均固定 B；不允许为图修复重新匹配轴。

高维 raw 的拟合是欠定问题，不能照搬四维最小二乘：使用带截距处理一致的 ridge 增量回归，以对偶形式求解；正则候选固定为相对设计谱尺度的 `10^-6、10^-4、10^-2、1`，仅按独立 CAL-check 的位移预测误差选取，平手选更强正则。特征标准化只用 TRAIN；常数维按预设方差下限处理。CNN 使用相同选择规则。这个比较保证信息和拟合规则相同，不宣称维度、函数复杂度或算力相同。

为防止四维瓶颈人为削弱 raw，另预设**全像素局部切向对照**。令像素或特征的中心剂量响应为 `A(I) ∈ R^(p×4)`，使用

`K(I) = (A(I)^T A(I) + λ I_4)^(-1) A(I)^T`

将局部可见变化映射到四个命名因素增量；两端梯形平均后沿参考图积分。实际只需求解 4×4 Gram 系统，**这不是把原像素当成四维可逆观测**。如果 A 不满列秩，则某个因素在该处不可恢复；伪逆不能补出丢失信息。正则和数值门只由 CAL 决定。该对照使用同样的查询响应，不额外获取真值。

主比较使用统一 B 读出以复现现有分解；全像素对照用于审查 learned 优势。只要它达到相同效果，就不能只凭瓶颈 raw 的失败声称 CNN 不可替代。若全像素与瓶颈读出差异很大，应先解释接口约束，不启动新的训练扫描。

## 5. 固定轴、固定分子，只替换参考尺度

令 N 为固定命名读出的直接增量分子，L 为局部逆响应恢复的分子，A 为固定读出的经验参考标准差，G 为可见图重建的经验参考标准差。D、P 分别是真实因素分子和参考标准差。

| 对照 | 计算 | 回答的问题 |
|---|---|---|
| 固定命名读出 | N/A² | 轴映射之后的原始慢排序 |
| 只修增量 | L/A² | 保持旧尺度时局部恢复的效果 |
| 同尺度读出，主干预 | L/G² | 分子、轴映射和样本完全相同时，参考尺度是否改变答案 |
| 真分母，仅揭盲后 | L/P² | 尺度修复还有多大可达改善空间 |
| 真分子，仅揭盲后 | D/A² | 增量估计是否仍是主要错误来源 |
| 物理评分 | D/P² | 目标慢集 |

同时记录每个轴的评价相关性、CAL 位移误差、逐滞后增量相对误差、参考标准差相对误差、排序间隔误差。评价因素相关性只是恢复诊断，不反向用于 B、阈值、图或模型选择。比较 L/A² 与 L/G² 时轴和分子逐元素相同，因而该配对差异可以归因到分母；这比仅看“因素相关性高、慢集却错了”更直接。

图邻接、正则、数值失败及回退规则在独立 CAL 后固定。图环残差小不能被称为物理误差界：一致的非线性坐标偏差可能穿过图残差检查。当前条件图界中的导数余项、最小奇异值和图谱量也不能因为图像维度高就自动成立。

## 6. 样本角色、最小证据与停止条件

若后续获准实施，建议最小主实验为一个既有 JEPA 目标、同一 CNN 架构的 3 个独立训练 seed，不先铺开方法矩阵。每个模型使用独立 TRAIN 与 CAL；不同模型可以共享评价面板以便配对，但不得把相同评价样本当成独立的模型重复。

建议沿用每工况 16 个独立参考及配套评价面板，每面板 96 条参考、128 条评价、每条 193 状态；不按真值间隔或已知错例挑窗口。先以密集参考查询检验机制，稀疏预算另立协议。正式预测、包括不作答与回退，须在揭盲前封存。

这套密集评价并不便宜：每工况每面板 345,856 个剂量分支，两工况共 11,067,392 个分支图像，3 个模型共享渲染、分别编码；另有基线帧和 CAL。若直接保存全部 float32 RGB 分支，约需 544 GB。仅一组 18,528 个参考节点的 8 剂量分支就约需 **7.29 GB（十进制）**，不能一次物化。实现必须分块渲染、编码并保留小型特征/响应缓存；全像素 raw 按块累积 Gram 与所需边积分，按面板流式处理，避免储存全部高维 Jacobian。正式启动前要对训练与评价分别测时；不能只报训练 GPU 小时，或把减少参考节点当成不改变实验的工程优化。若预算无法承担，应在正式数据生成前重新冻结更小设计，并重新检查其可测性。

以下为供审阅的最低门槛；正式实施前应连同训练预算、种子、正则和数值门写入不可变协议。

1. **接口与可评价性门。** 极小 CPU 样本验证同一图像复现、单因素剂量配对、输出形状、无真值进入读出、数值响应的秩；不得用这些工程样本报告科学收益。正式样本须报告全部可用率；图可用至少 15/16 面板、局部响应可用至少 95% 窗口，未达则视为该实现未能检验主机制，不能删除困难样本后宣称通过。
2. **前瞻主门。** 主工况 L/A² 错选率减 L/G² 错选率，3 个预定 seed 都为正，等权平均至少 1 个百分点；每个 seed 单独按完整参考面板配对重抽样 4096 次，其双侧 95% 区间下端均大于 0。该门支持这 3 个模型上的重复，3 个 seed 不足以估计所有训练模型的总体分布。同源 ε=.5 对照另报，不混合抵消；它不是 ε=.08 训练后迁移到 ε=.5 的反向试验。
3. **机制解释门。** 揭盲后，真分母替换的间隔 MAE 改善大于真分子替换；L/P² 相对 L/A² 的间隔 MAE 至少下降 50%。若前瞻改善存在但这一门失败，只报告修复有效，不再将机制概括为“分母主导”。若 L/P² 本身几乎不改善，图修复无效不能归因于图算法差。
4. **恢复条件核对。** 不用评价真值筛掉不满足恢复条件的模型。逐模型报告因素恢复、分子误差与分母改善空间；条件没有出现，结论为所训模型未进入待验证情形。若只有经事后挑选的模型成立，不算预定主门通过。
5. **错误与覆盖同时报告。** 所有窗口计入总体错选和回退。另按封存的可见预测间隔排序，报告 10%、25%、50%、75%、100% 覆盖下的真实错选率，及修复旧错、引入新错数量；局部/图拒答率单列。可见读出一致性只说明两个规则同意，选择性风险曲线是经验评价，不称为置信证书。

若没有可评价模型、没有预定效应，或同信息 raw 消除了所谓 learned 优势，本轮即按相应边界收缩，不补训练 seed、不改主工况、不靠事后挑选间隔救结果。物理间隔分层只用于解释。

## 7. 哪些工作需要训练，哪些只需评价

渲染、CAL 读出、剂量响应、图重建、封存、风险与覆盖评分均不需要训练表示。若找到来源与数据角色清楚的适用图像 checkpoint，可以仅做这些评价；不能把不适用的两因素模型改个输出解释后当成四因素验证。

本机现有 Fine checkpoint 接收低维观测，不能直接处理这些图像。使用上述图像世界时，需要训练或另获适用的图像编码器。建议先复用已有 CNN 加既有 LeJEPA alignment/SIGReg 目标，输出维度 4，固定最终 checkpoint，不设计新训练损失。论文应称其为图像 JEPA 实例，不能把它描述成现有 HCF 可逆 Fine 的无修改迁移。训练数据、常规预处理和目标中的可见动作信息须另外明确；不得把因素标签用于早停。

预算草案为最多 3 个 seed、每个固定 20,000 次更新、batch 256；单一正则权重在实施协议中确定，不运行整个官方超参数网格。正式锁定前需要一次独立工程基准估算内存与时长；若资源不适配，应在正式数据产生前修订预算并记录，而不是在结果出现后延长训练。这里没有声称这个预算已足以学到因素。

因此，**理论分析论文不必先发明新方法才有理由使用 GPU**。GPU 的明确产出是新的、独立训练的图像表示，用来检查当前条件机制能否在高维输入上出现。它不补足未证明的余项常数，不替代同信息 raw，也不把有限参考经验结果变成总体证书。

## 8. 本轮跨冻结模型结果如何改变去留

本节列出去留所依据的证据分支，随后结合本轮结果给出判断。

| 本轮跨模型结果 | 图像方向的判断 |
|---|---|
| 新 seed 与反向工况均通过前瞻和归因门 | 有理由进入图像接口实现与一次小规模 GPU 机制验证；主问题仍为尺度一致性 |
| 新 seed 通过，反向工况不通过，但真分母替换也无明显改善空间 | 形成“有偏差且跨越间隔才需修复”的条件机制；可以设计一正一负工况的图像验证，避免把普遍改善写进主张 |
| 有明显真分母改善空间，图修复在新模型失效 | 先查可见图重建的适用性；增加 GPU 模型不能直接解决这一已定位问题，暂缓图像训练 |
| 新 seed 也没有复现，或主要错误重新来自因素/增量丢失 | 当前尺度主导机制局限明显；保留条件理论与个案诊断，不将图像训练作为默认下一步 |
| raw 与 learned 都有效 | 支持通用读出机制；论文不主张 learned 独立优势 |

无论本轮哪一分支成立，原 64 节点效率门均维持未通过。若另立图像稀疏查询方法课题，需要新的可观测控制、成本核算和独立协议。

**本轮结果追加：跨模型复现支持进入小规模图像验证的准备阶段。** 两个设置的前瞻效应与事后归因均通过；所有图与局部安全门通过。每设置 2,048 个评价窗口，统计重抽样单位是 16 个参考与配套评价面板，面板内窗口共享参考尺度：

| 冻结模型设置 | L/A² 错选 → L/G² 错选 | 错选率净下降及配对 95% 区间 | 真分母替换的间隔 MAE 改善 |
|---|---:|---:|---:|
| ε=.5 seed 1 → ε=.08 | 204 → 6 | 9.67 pp [8.30, 11.04] | 99.13% |
| ε=.08 seed 0 → ε=.5 | 285 → 1 | 13.87 pp [12.60, 15.14] | 98.66% |

同信息 raw 图读出分别错 8 和 0 个，支持通用尺度修复，不支持 Fine 独立优势。只替换真分子几乎不改善间隔误差，密集修复剩余 7 个 Fine 错例全部位于物理间隔 ≤.01。上述结果定位了值得上图像验证的机制，同时保留间隔边界。[正式结果与证据链](RESULTS.md)

据此保留 ε=.5 训练、ε=.08 主评价与 ε=.5 同源辅助评价的设计方向。**建议下一项是接通并审核完整图像数据与读出接口，然后使用明确预算训练 3 个既有目标的 CNN，检验机制外部有效性；现在没有必要先发明新的 HCF 训练方法。** 实际进入 GPU 仍须完成独立实施协议和用户授权。本轮授权范围内的交付为此设计、本机复现及四状态渲染自检，未实现完整图像系统或开始训练。
