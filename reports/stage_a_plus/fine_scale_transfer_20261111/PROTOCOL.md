# 冻结 Fine 的参考尺度机制复现

问题是更换冻结模型或反转 FHN 工况后，能否复现两个预测。用同一局部恢复分子时，可见参考尺度能降低逐窗口 top-2 错选。将两项估计分别替换为物理真值时，参考尺度替换对间隔误差的改善更大。

## 模型、信息与样本

- 固定 FHN ε=.5 seed 1 → ε=.08 与 FHN ε=.08 seed 0 → ε=.5。前者改变训练 seed，后者改变源和目标工况。旧 ε=.5 seed 0 → ε=.08 只作历史参照。
- 两组模型均使用已有物理轴对应，仿射读出按独立命名剂量 CAL 拟合。轴对应是已有监督信息。新评价的物理状态只用于评分，模拟器内部可以使用状态生成指定的可见剂量分支。
- 分别重放旧 active 第 0 组 CAL/query 种子 `2026160000/2026175000` 和 `2026159000/2026174000`，各 96 条。轨迹 ID 对 4 取余为 0 的 24 条用于拟合，时点为 8、24、40、56、72、88、104、120，拟合四轴 +.035 剂量的响应映射。余数为 1 的 24 条的 −.0175 分支只作校准核对。模型各自拟合映射，正式参考与评价种子和历史 CAL 分开。
- 每模型 16 组。每组独立抽 96 条参考和 128 条评价轨迹，每条 193 状态。所有评价窗口均查询，不按旧分数筛选。参考与评价种子为 `2026346000 + 1000*m + g` 与 `2026346200 + 1000*m + g`，`m` 取模型列表顺序的 0、1，`g` 为 0 到 15。工程样本每角色 8 条，种子 `2026345900 + 10*m` 与相邻下一值。
- 同一组的所有规则共享全部参考和评价可见观测。每节点查询四个命名轴的 ±.0175 剂量，共 8 次分支。比较参照为该组独立 96 条参考轨迹的经验物理方差。慢度取 4、16、32 步平方增量均值的等权平均。输出命名 top-2。

## 对照和判定

令 L 为冻结局部逆响应梯形积分得到的分子，A 为固定仿射参考尺度，G 为冻结密集图恢复的参考尺度。D 为评价的真实物理分子，P 为经验物理参考尺度。预先封存原生 Fine、固定仿射、L/A² 和 L/G² 的四轴分数。图失败时 L/G² 回到 L/A²。评价窗口的局部数值门失败时两者都使用固定仿射分数。沿用冻结局部和图数值门。每个模型的比较纳入所有无物理分界平手的窗口，规则分界平手记为未给出正确选集。

1. **前瞻效应。** 主效应为 L/A² 错选率减 L/G² 错选率。每模型点差至少 1 个百分点且双侧配对 95% 重抽样区间下端大于 0。图可用至少 15/16 组，局部响应安全至少 95% 的窗口。按参考与配套评价整组重抽样 4096 次，两个模型分开估计。只在两个模型都满足时称为双重复现。
2. **事后归因。** 在图可用且局部安全的窗口，用同一原生 Fine 选集计算估计与物理的有符号间隔。分别评分 L/P² 与 D/A²。间隔 MAE 的差 `MAE(D/A²) − MAE(L/P²)` 衡量只替换分母相对只替换分子的改善。下端须大于 0，且 L/P² 相对 L/A² 的间隔 MAE 减少至少 50%。报告四组合及原生、仿射、图规则的错选率与间隔 MAE。
3. **边界检验。** 用物理第 2 与第 3 分数的差分层，边界固定为 .01 和 .03。记录各层错选、修复、引入错误及图数值可用率。物理分层只用于事后解释。另封存一个可见稳定性条件。若 L/A² 的分界间隔严格大于两套分数差的极差，则两套读出给出同一选集。报告条件覆盖率及物理错选风险，借此区分读出之间的可见稳定性与对物理目标的正确性。可见条件不使用评价真值。

同信息 raw 使用相同可见剂量、独立拟合仿射读出和相同图与局部校正，评价自己的命名 top-2，作为预设次要对照。两个设置各自使用种子 `2026346800 + m` 生成整组重抽样索引。报告分支成本和共享范围。

所有预定阈值都在正式预测前记录。先封存预测再评分。工程试跑要求剂量回放一致，历史分数、显式归一化和代数一致性误差均不超过 `1e-9`。数值可用性在试跑中记录，在正式样本按第 1 项的门判定。既有 64 节点效率实验保持其原判定。若两工况的结果不同，先在本次数据范围内找分母替换的改善空间和分子余误差，再决定图像验证主张。
