# 参考尺度机制在两个冻结 Fine 设置中复现

用同一局部恢复分子，只替换参考尺度，两个设置的逐窗口慢集错选率分别降低 **9.67** 和 **13.87** 个百分点。两项前瞻判定和两项事后归因判定均通过。密集查询也能修复同信息 raw，因此这组结果支持参考尺度的机制主张。 [预设协议](PROTOCOL.md) · [完整结果](SUMMARY.json)

## 独立数据上的慢集错选

每个设置包含 16 个独立组，每组 96 条参考与 128 条评价轨迹。所有 4,096 个评价窗口均参加主比较，直接评分每条规则自己的命名 top-2。两个设置中，Fine 和 raw 的参考图各 16/16 可用，所有评价窗口均通过局部数值门，物理分界无平手。

| 规则 | ε=.5 seed 1 → ε=.08 错选 / 2,048 | ε=.08 seed 0 → ε=.5 错选 / 2,048 |
|---|---:|---:|
| 原生 Fine | 155（7.57%） | 145（7.08%） |
| 固定仿射 Fine | 118（5.76%） | 71（3.47%） |
| 局部恢复 + 旧仿射尺度 | 204（9.96%） | 285（13.92%） |
| **局部恢复 + 可见图尺度** | **6（0.29%）** | **1（0.05%）** |
| 同信息 raw 固定仿射 | 369（18.02%） | 171（8.35%） |
| 同信息 raw 局部恢复 + 可见图尺度 | 8（0.39%） | 0（0.00%） |

第一个设置修复 198 个旧错例，新引入 0 个，净下降 9.67 个百分点，整组配对重抽样 95% 区间为 [8.30, 11.04]。第二个设置修复 285 个旧错例，新引入 1 个，净下降 13.87 个百分点，区间为 [12.60, 15.14]。统计单位是整组参考与配套评价轨迹，每个设置各 16 个独立单位。Fine/raw 的小差距只作描述，两者都接近该设置下可测的零错选。

## 分子与分母的事后拆解

下表的间隔统一计算在原生 Fine 选集上。四个替换组合中的物理分子或分母仅在预测封存后使用。实验目标由每组经验物理参考方差定义。

| 组合 | ε=.5 seed 1 → ε=.08 间隔 MAE / 错选 | ε=.08 seed 0 → ε=.5 间隔 MAE / 错选 |
|---|---:|---:|
| 估计分子 + 旧分母 | .039763 / 204 | .083660 / 285 |
| 真实物理分子 + 旧分母 | .039775 / 204 | .084083 / 285 |
| 估计分子 + 经验物理分母 | .000347 / 2 | .001119 / 2 |
| 真实物理分子 + 经验物理分母 | 0 / 0 | 0 / 0 |
| 估计分子 + 可见图分母 | .000444 / 6 | .001001 / 1 |

只替换物理分母，间隔 MAE 相对旧规则分别减少 99.13% 和 98.66%。只替换物理分子时，错选数保持 204 和 285。两种单独替换的 MAE 差分别为 .03943 和 .08296，整组配对区间为 [.03837, .04054] 和 [.08104, .08496]。这些对照把当前数据中的主要误差定位到尺度错配。两项误差可以相互抵消，因而不能把这个比例解释为一般的误差分解。

Fine 的逐轴参考标准差平均相对绝对误差从 1.440%、1.262% 降到 0.0194%、0.0086%。同信息 raw 的图尺度误差为 0.0601%、0.0188%。这是对两个冻结模型及当前生成器的结果。反向工况同时更换了模型和目标环境，因此它给出不同设置中的复现。

## 接近慢度分界时的可靠性

| 物理第 2 与第 3 慢度间隔 | ε=.5 seed 1 → ε=.08 窗口数与旧/图错选数 | ε=.08 seed 0 → ε=.5 窗口数与旧/图错选数 |
|---|---:|---:|
| ≤.01 | 118，60 → 6 | 66，34 → 1 |
| (.01, .03] | 203，76 → 0 | 134，77 → 0 |
| >.03 | 1,727，68 → 0 | 1,848，174 → 0 |

旧规则在中、大物理间隔也发生错选，说明误差必须与间隔比较。密集修复后的 7 个错选全出现在物理间隔 ≤.01 的窗口。该间隔用于事后分层。

另有一条只用可见分数的规则，比较旧分界间隔和两套分数变化的极差。满足严格不等式时，两套规则必然同选。条件覆盖分别为 1,422/2,048（69.43%）和 1,229/2,048（60.01%）。这些窗口上两套规则均无观测错选。这个条件保证的是本次两套分数之间的稳定性，物理正确率来自封存后的经验评分。

## 边界与交付

本轮使用已有物理轴对应、独立的命名剂量 CAL、参考与评价中的密集配对扰动。每组新增 345,856 次物理分支读出，两种表征共享分支。32 个正式组共 11,067,392 次分支，既有校准和训练成本另计。所有训练权重冻结，预测和评分分别耗时约 75 秒和 9 秒，均用本机单线程 CPU。

两种工况的结果为后续小规模图像验证提供了依据。下一项要检验的主命题是，在更高维观测里，已恢复的动态分子能否通过可见参考尺度校准改善慢集排序。固定剂量与轴对应仍是本次证据的条件。原 64 点查询的非劣性未建立，该方法主张保持原判定。 [图像验证设计](IMAGE_EXPERIMENT_DESIGN.md)

双光斑渲染接口已在四个固定状态上用 CPU 核对。各轴的配对剂量能改变相应光斑，像素可重复，矩形响应为满列秩。饱和测试状态的条件数约 101，其他三个为 1.00–2.24。这个差异为图像协议中的响应可用性检查提供了具体依据。完整图像训练与评分管线仍待实现。 [接口核对](IMAGE_INTERFACE_CHECK.json)
