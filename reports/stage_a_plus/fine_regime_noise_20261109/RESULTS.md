# 工况标签噪声的结果

物理轨迹保持不变，只替换校准标签。随机替换概率 .50 时，标签实际不同的比例约 .44，经验差分在干净差分上的投影系数为 .496 和 .500。总体的线性衰减关系在这个读数上得到复现。慢集精度并不随缩放自动保持。

| 预测输入 | 替换率 | FHN ε=.08 近边界命中 / 1,035 | FHN ε=.5 近边界命中 / 662 |
| --- | ---: | ---: | ---: |
| Fine 等变读出 | 0 | 780 | 509 |
| Fine 等变读出 | .25 | 786 | 498 |
| Fine 等变读出 | .50 | 735 | 451 |
| Fine 等变读出 | .75 | 646 | 396 |
| 原 Fine | 无方向校准 | 788 | 493 |

.50 相对 0 的近边界差为 **−4.35、−8.76 个百分点**，单侧 98.75% 下界 −7.98、−13.42，均未过 −3 个百分点的保留门。等量预警由 111/273、124/216 降至 101/273、109/216。相对干净标签，前一槽警报保留通过 −10 个百分点门，后一槽未通过。干净基准白化的额外信息没有恢复该损失。

完全替换时，Fine 的 32 个校准组中有 28、29 组无法使用方向读出，输出的大部分来自回退原 Fine。该档不能按总体命中率解释方向仍有效。这个结果约束随机工况标签噪声的容忍度，物理机制与训练权重没有变化。
