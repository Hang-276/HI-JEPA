# Stage 1 · 区分窗口界的松弛与校准信息不足

本轮延续 [状态依赖剂量实验](../dose_state_dependent_20261110/PROTOCOL.md) 的两个非恒等坐标 \(h(x)=x+.25\tanh(x)\) 与 \(h(x)=x+.25\sin(x)\)。四个独立标准 Gaussian AR 轴的系数为 .95、.9495、.995、.20。窗口为 193 个状态，评分用 4、16、32 步平方增量的等权平均，并按物理坐标在固定 Gaussian 参考下的总体方差归一化。判定目标是当前窗口的物理 top-2。只有轴 1 的物理坐标未知，所有候选共用已知全局斜率盒 \([.70,1.30]\)。

每面板只用旧主预算。在 \([-4,4]\) 的 101 个等间距已知起点，每点施加 .16 与 .32 两种物理剂量，每种重复 20 次，共 4,040 次查询。独立 Gaussian 读数噪声标准差为已知的 .02。按上一轮的同一规则对全部 202 个响应均值给出 99% 同时置信区间。两个物理世界共用评价轨迹和校准噪声，响应读数由各自真实坐标决定。精确网格诊断在同样起点提供精确响应均值，把置信半径设为零，其余规则一致。

## 三条冻结规则

- **A** 完整复用上一轮冻结的预测代码和规则。它传播剂量差分约束，分别包络窗口分子 \(N\) 与 Gaussian 参考方差 \(V\)，并保留上一轮的安全作答逻辑。
- **B** 在可行图中保留旧参考和评分网格，并纳入剂量响应区间的精确端点约束。用同一候选图分别给 \(N\) 和 \(V\) 作保守上下界，再通过分离界与其余三轴中第二小分数 \(B_w\) 比较。B 和 C 使用同一组平方函数切线、割线仿射外界，使二者对照只改变分子和分母是否联合优化。
- **C** 在 B 的同一候选图上，联合优化 \(N-B_w V\) 的两个仿射外界。对下界取可认证的最小值下界，对上界取可认证的最大值上界。只有经过向外数值校验的区间与零严格分离，才新增作答。不能认证的求解保留已有安全作答，否则拒答。B 保留 A 的安全作答，C 保留 B 的安全作答。若安全结论冲突，记为工程失败。

这里的 \(B_w\) 是窗口中的已知比较分数。精确响应指只更换可见校准输入，算法在预测时仍看不到真实物理坐标、参考方差或物理选集。精确响应格用于定位这套规则对当前校准不确定性的敏感性。

## 用相反物理解释见证拒答

对 C 在带噪格仍拒答的窗口，从候选图构造显式分段线性的两套物理坐标。每套都要独立核验其全局延拓与斜率盒、每条剂量响应是否落在相应置信区间，以及实际窗口分子和 Gaussian 参考方差。只有严格验证两套坐标的 \(N-B_wV\) 异号才计作已见证歧义。见证的选择和核验只使用预测时可见数据、已知结构和候选坐标。未找到合格见证的窗口列为未分辨。按物理世界分别报告见证数、未分辨数和见证占 C 剩余拒答的比例。见证可以随窗口改变，结论针对该面板的候选类。

## 数据分工、工程门与独立评分

- 工程试跑只读上一轮正式面板 0 的封存预测和可见数据。在 tanh 主预算按原窗口索引分别取 A 已接受的前 8 条和 A 拒答的前 8 条。这 16 条同时用于两个物理世界。核对 A 与旧预测逐条一致、置信端点约束、B 与 C 的可行性和向外证书、逐条作答保留、见证的独立重算。工程读数只用于通过检查与估算成本。
- 正式使用根 2026287102。24 个独立校准–评价面板各配 128 条新窗口，共 3,072 条。校准与评价采用分开的派生流，两个世界保持配对。根 2026287103 用于固定 4,096 次按面板重采样。先锁定协议、实现和复用源，工程通过且预计正式单线程不超过 2 小时才进入正式。先封存可见输入、预测与见证，再揭示物理评分。全部计算使用本机单线程 CPU。
- 按物理世界报告 A、B、C 的覆盖、无条件错误接受、给定作答错误率，及置信区间失覆盖的面板数。覆盖差以配对面板为单位，报告 95% 重采样区间。另报精确响应与带噪下同一规则的覆盖差。

## 去留判据

- **覆盖门。** 带噪主格中 C 相对 A 在两个世界均新增至少 5 个百分点。在真响应位于同时置信区间的全部面板中，三条规则不得错答。B 相对 A 和 C 相对 B 分开报告，后一差值用来判断联合约束的独立贡献。
- **若覆盖门未过。** 用精确响应格和拒答内证区分剩余障碍。若每个世界中至少一半的 C 剩余带噪拒答有严格异号见证，将下一步优先级放在校准信息。否则只报告已见证部分以及未分辨比例，精确响应差作为定位依据。
- **停止。** 工程门或安全核对失败即停止。无论覆盖门结果，本轮使用固定面板、窗口和 4,040 查询预算收尾。无追加样本、训练、网格或参数搜索。
