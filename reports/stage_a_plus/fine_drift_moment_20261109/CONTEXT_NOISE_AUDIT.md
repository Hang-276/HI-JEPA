# 同预算配对状态、噪声及相反符号的诊断

在前一轮封存的 32 个校准组内，取五块不重叠的同大小轨迹，每个工况固定 14 条、每条 8 个时点。干预生成器分别让五臂共用或分用状态块、共用或分用同样大小的高斯抽样，并比较是否平均正负符号。固定同一源与目标漂移。这里只计算矩，未重新评分物理轨迹。以下数字是每面板四轴中最大相对 D 变化的中位数。

| 干预设计 | .08→.5 | .5→.08 |
| --- | ---: | ---: |
| 不共享状态、不共享噪声、单符号 | .997 | .965 |
| 不共享状态、共享噪声、正负平均 | .962 | .919 |
| 共享状态、不共享噪声、单符号 | .901 | .722 |
| 共享状态、共享噪声、单符号 | .420 | .397 |
| 共享状态、不共享噪声、正负平均 | .0122 | .00539 |
| 共享状态、共享噪声、正负平均 | .0109 | .00513 |

不匹配状态时，相反噪声平均后仍有接近 1 的矩差。匹配状态后，正负平均显著缩小漂移敏感性，噪声是否在工况间共用的额外影响相对小。单符号下共享噪声本身有明显作用。这个交叉诊断支持两个条件分别重要。匹配过去状态消去各工况不同的漂移误差能量分布。正负噪声平均抑制共同状态下方差干预响应的一阶随机项。剩余小量来自非线性表示的偶次项及数值估计。

这些是已知模拟器下的矩诊断，未评估它们在被动轨迹中能否由近邻或加权替代。可以直接在旧被动数据用可见残差拆开“漂移差的平方项”和“与剩余创新的交叉项”，检验哪一项使导出的方向偏移。
