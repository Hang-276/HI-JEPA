# Frozen encoder readout experiment

The experiment uses all 16 archived LeJEPA encoders across four Gaussian AR(1) cases and four encoder seeds. Encoder weights are frozen and verified against the prior forecast receipt. Each encoder is paired with two fixed readout seeds and four arms. All data draw master 2026111304. CAL and VAL use independent role streams with 128 and 64 independently initialized stationary trajectories respectively, each of length 193. Across the four cases, the underlying innovations are paired and the recursion uses the corresponding locked rates. All arms use the same CAL and VAL samples, CAL-standardized encoder inputs, and exactly the same lag/trajectory/time minibatches and decoder initialization within a seed. Lags are drawn independently and uniformly from 4, 16, 32. For a chosen lag, the pair samples one trajectory and a uniform admissible starting position.

The physical readout is a two-hidden-layer width 128 SiLU MLP. AdamW with weight decay .0001 uses learning rate .001 for the first half of updates, followed by a cosine schedule. Each readout runs 3,000 updates of 256 endpoint pairs. At steps 250, 500, ..., 3,000, record VAL R² for all axes. Use the final update for every arm. VAL monitoring cannot select weights, optimize a hyperparameter or stop training. The predeclared matching subset has maximum absolute per-axis VAL R² difference between state and temporal lambda 1 no greater than .005. Include all pairs in the primary reporting. Contrast true temporal lambda 1 with state and with shuffled lambda 1. The lambda .1 arm measures dose descriptively.

All arms compute endpoint state MSE over both endpoints, axes and batch elements. In the temporal arms, the increment MSE between predicted and true differences is divided by 2. The combined loss is (state MSE + lambda × increment MSE) / (1 + lambda). The shuffled control rolls the entire batch of future predictions and future labels together by one position after endpoint supervision. Both future arrays have the same reordered endpoint membership. This preserves state supervision and preserves an increment-like residual cross-term with mismatched temporal pairs. It need not equal a state-only optimization at finite batch or even at its population optimum under nonzero residual means. The control isolates true versus mismatched pairing for this particular loss.

TEST uses 1,024 new trajectories of length 513 per physical case and shared innovations across cases. Score nested prefixes of lengths 65, 193 and 513. Length 193 is primary. Reference uses eight independent banks of 32,768 stationary iid samples each, shared across cases, checkpoints and arms. Use each readout's own variance for its scores, also archive its first and second moments for pooled variance analysis. The physical target uses variance 1. Decoder and reference forward computations complete before the label file is generated. The input simulator states during forecast only feed the observation map. The separate reveal stage recomputes the physical states from the locked stream after validating all forecast hashes. No test labels inform readout training or model selection. Save float32 state predictions and float64 reference moments. CPU only.
