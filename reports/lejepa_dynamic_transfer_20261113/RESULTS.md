# LeJEPA 动态恢复到可靠慢集的系列实验

2026-11-13。本轮完成 128 个诊断读出的配对训练、两轮独立参考与评价、窗口长度和参考设计敏感性、状态匹配检查，以及一个精确解析反例。结果不支持把当前简单的增量 MSE 辅助损失作为解决慢集可靠性问题的主要方法。在已强恢复的模型上，它有约 0.1 个百分点的小收益，未达到预设 1 个百分点实效门；在两个预指定弱恢复模型上，增量误差下降而选集表现变差的现象得到了独立复验。

## 实际完成的实验

沿用四条件各四个 LeJEPA 编码器，权重均冻结。每个编码器使用两个新读出初始化与四个损失臂，共 128 个读出。四臂共享同一 CAL、VAL、输入端点、状态标签、初始化、mini-batch 计划、网络结构、更新数和学习率日程，唯一规定的改变是辅助损失。

| 读出臂 | 训练目标 | 要检验的问题 |
|---|---|---|
| state | 两端点状态 MSE | 基线 |
| temporal .1 | 状态 MSE + .1 倍增量误差 | 较弱干预的剂量趋势 |
| temporal 1 | 状态 MSE + 增量误差 | 动态监督能否明显改善选集 |
| shuffled 1 | 相同权重，但将完整未来端点与其标签一起错配 | 收益是否依赖真实时间对应 |

增量误差为预测增量与真实增量之差的 MSE 除以 2，总损失再除以 1+lambda。lag 4/16/32 均匀采样。错配是在随机 mini-batch 上固定循环移位，不是错误标签监督，也不是严格独立端点采样。所有读出为两隐藏层各 128 单元 SiLU MLP，固定末步 3000，VAL 只监控与定义预设可比子组，不选择 checkpoint。

CAL 为 128 条、VAL 为 64 条独立平稳轨迹，各 193 状态。每轮 TEST 为每条件 1024 条 513 状态轨迹；65、193、513 状态前缀共享路径，193 是主分析。每轮有八份独立参考，每份 32768 个 iid 状态。主预测使用每个读出自身经验方差，准确率对八份参考等权平均。物理答案始终用总体方差 1。不同模型共用评价路径、不同条件共用基础创新，统计保留这些配对关系。

初轮 master 为 2026111304，复验仅更换为 2026111305，全部参数、状态匹配名单与评分代码不变。两轮都先保存预测和散列，再独立揭盲。不合并结果，不降低门槛。原 14 个强恢复 checkpoint 根据上一轮独立实验预先固定，两个谱交错 seed 7811 checkpoint 是弱恢复压力组。

本机四个单线程 CPU worker 完成全部拟合，最慢一组约 69 秒，worker 总计约 275 秒，初轮预测约 40 秒。没有新训练编码器、访问服务器、缩减封存后的预算，或改变原 LeJEPA 架构。本轮仍是低维受控研究。执行与数据身份见 [首轮记录](experiment/EXECUTION.md) 和 [复验记录](experiment/replication/EXECUTION.md)。

## 1. 高恢复组有稳定但很小的选取收益

| 强恢复组，193 状态，八参考平均 | 首轮准确率差 | 独立复验准确率差 |
|---|---:|---:|
| temporal 1 − state | +0.132 个百分点 | +0.103 个百分点 |
| temporal 1 − shuffled 1 | +0.117 个百分点 | +0.080 个百分点 |
| 预设 1 个百分点实效门 | 未通过 | 未通过 |

首轮两差值的配对重抽样 95% 区间为 [0.076,0.188] 和 [0.068,0.167] 个百分点；复验为 [0.056,0.152] 和 [0.033,0.129]。两项同时单侧下限均大于零，但点收益均低于 1 个百分点。这里的重抽样条件于固定编码器与已拟合读出，共享整条 TEST 轨迹和整份 REF 的索引，不能将大量重复评分解释为大量独立训练重复。

这些为百分位重抽样区间，不是有限样本的精确覆盖保证。

首轮强组 state 准确率 95.178%，temporal .1 为 95.204%，temporal 1 为 95.310%，shuffled 1 为 95.193%。temporal 1 相对 state 每 1024 个窗口平均修复约 2.66 个，同时引入约 1.31 个新错选。动态监督的可测收益很小，未支撑预设的实效主张。见 [首轮完整评分](analysis/RESULTS.md) 和 [独立复验](analysis/replication/RESULTS.md)。

## 2. 状态恢复近似匹配，没有确立独立的动态误差结构效应

32 个编码器×读出种子配对中有 28 个满足 VAL 四轴最大 R2 差不超过 .005。要求两个读出种子同时通过后得到 14 个编码器，覆盖四条件，恰与历史强恢复组重合。该名单在本轮 TEST 揭盲前锁定。

不过，在高 R2 条件下，绝对 R2 差很小仍可对应残差能量的明显相对变化。首轮强组 temporal 1 相对 state 的端点状态 MSE 下降 2.754e-4，残差跨 lag 非中心积均值下降 1.250e-5，增量 MSE 总计下降 5.259e-4。复验相应为 2.730e-4、1.181e-5 和 5.224e-4。增量改善主要伴随更小的状态误差；残差跨 lag 积的变化反而抵消一小部分改善。首轮跨 lag 积与端点 MSE 的比值也由约 .03652 降到 .03609。

所以，近似状态匹配门通过不等于把全部状态恢复差异消除了。当前数据没有独立确立“改变残差时间结构，在相同状态能力下带来实用保序收益”的机制。测试真值展开的恒等式只用于这个解释，不能当作预测能力证明。

## 3. 弱恢复模型上，增量误差改善和排序恶化同时复现

| 两个弱恢复模型，193 状态 | 首轮 | 独立复验 |
|---|---:|---:|
| state 平均增量残差 MSE | .34031 | .33662 |
| temporal 1 平均增量残差 MSE | .33602 | .33235 |
| temporal 1 − state 准确率 | −0.467 个百分点 | −0.342 个百分点 |
| temporal 1 − shuffled 1 准确率 | −0.934 个百分点 | −0.720 个百分点 |

复验四个读出种子配对的增量 MSE 均优于两对照，top-2 相对 state 四项均下降，相对 shuffled 三降一平。该组由同一编码器初始化下的两个物理条件构成，不能推广成所有弱恢复模型的规律。

错选方向也一致。首轮 temporal 1 相对 state 的最快轴误纳入率由 12.31% 升至 13.28%，误排除率由 3.79% 降至 3.40%；复验误纳入率由 14.00% 升至 14.72%。增量误差减少没有消除让最快轴错误进入慢集的那部分误差。跨界最小间隔的负部均值，两轮都增加。

首轮最快轴的增量残差 MSE 下降 .01643，但真实增量与残差增量的两倍交叉项增加 .02440，使动态分子的有符号偏差改变 +.00796。分子与参考分母共同作用于最终分数，不能只凭其中一项绝对误差判断排序方向。把物理方差 1 代入预测分母能改变部分效果方向，但这同时改变解码坐标的尺度，只作 Oracle 诊断。

## 4. 参考池和窗口长度没有使强组收益达到实效门

首轮将八份参考按一阶、二阶矩正确合并，强组 temporal 1 相对 state/shuffled 的收益为 +.167/+.129 个百分点，仍很小。改变窗口长度也不改变这一判断。

| 首轮窗口状态数 | 强组相对 state | 强组相对 shuffled | 弱组相对 state | 弱组相对 shuffled |
|---|---:|---:|---:|---:|
| 65 | +.149 | +.123 | +.128 | −.256 |
| 193，主分析 | +.132 | +.117 | −.467 | −.934 |
| 513 | +.079 | +.063 | −.705 | −1.038 |

单位均为百分点。窗口使用同一路径的嵌套前缀；这些是预定敏感性分析，不是替代主终点的新门。弱组在不同长度上的符号变化说明，读出与窗口定义共同影响选取表现，不能泛化成越长必然越可靠。

## 5. 精确反例解释了平均增量误差为什么不够

另外构造并独立核验了一个无参考噪声的总体反例。四个物理轴都是独立标准化 Gaussian AR。两个可逆候选读出都只改变第三轴，状态 R2 完全相同，约 .990074，各输出方差均精确为 1。

| 候选第三轴 | 第三轴增量误差 | 总体慢集 |
|---|---:|---|
| 混入较快的第四轴 | .01491373 | {1,2}，正确 |
| 混入较慢的第一轴 | .01218452 | {1,3}，错误 |

后一个候选增量误差更小，对本轮任意正动态权重的损失也更小，却翻转了总体慢集。两个候选都保留全部因素信息。该反例证明“相同高状态 R2 加更低增量 MSE”仍不是保序充分条件，关键还包括误差的混入方向及其与动态分数的耦合。

反例比较两个不完美候选，不证明充分表达能力下的全局最优解会选择错误候选，也不是实际 LeJEPA 训练结果。其推导、长窗口适用说明和确定性核验见 [理论说明](THEORY.md) 与 [数值核验](THEORY_CHECK.json)。

## 研究决定

当前这套简单增量监督保留为机制对照，暂不作为主要方法贡献推进。两轮都得到小幅正效应，但未达到实效门；预先指定的弱恢复组还显示了与平均动态误差改善相反的选取变化。

更值得继续解释的量是跨慢集边界的有符号分数误差、误差的动态方向，以及分子与参考尺度的耦合。后续若提出新修正，应先给出这些量在独立数据上的可检验预测，再讨论是否能减少物理标签或形成可观测保证。本轮不将损失改进、Oracle 替换或近似状态匹配直接升级为通用保证。

全部原始拟合、预测、两轮独立结果、失败门槛与辅助诊断保留。见 [研究方案](RESEARCH_PLAN.md)、[冻结分析协议](analysis/PROTOCOL.md) 与 [独立审计](AUDIT.md)。
