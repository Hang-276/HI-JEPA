# 冻结 LeJEPA 动态读出独立评分协议

复用原 16 个编码器和每个编码器的两个固定读出种子。四个拟合臂为状态 MSE、动态系数 .1、动态系数 1、系数 1 的随机错配端点对照。使用每臂 3,000 次更新后的同一步参数。主对比固定为 temporal_1 减 state、temporal_1 减 shuffled_1。先报全部编码器。历史强恢复组用于检验可读信息充足时的机制，固定为上一轮独立复验中，两种评价动力学、四个物理因素的 MLP 线性评价最低 R² ≥ .85 的 checkpoint。两个谱交错 seed 7811 模型单列，历史名单与上轮源散列保存在 `HISTORICAL_GROUPS.json`。

按独立 VAL 的四轴最大绝对 R² 差 ≤ .005 固定 temporal_1 与 state 的近似状态匹配，必须在本轮 TEST 物理真值读取之前封存。编码器的两次读出种子均满足才纳入。至少 8 个编码器且四条件均有代表方可解释为具代表性的近似匹配。对同一子组也比较 temporal_1 与 shuffled_1，另列 placebo 状态差。匹配只作诊断，不删改主总体。分别报告每条件、编码器、读出种子的匹配状态。固定窗口 193 状态为主分析，65/513 使用同一条测试轨迹前缀作敏感性。目标为 lag 4、16、32 等权平方增量均值除以真实总体参考方差 1。排序按轴索引稳定破平。

主预测使用每个探针在每个独立 REF 面板的自身经验方差；先逐面板评分，再等权平均 8 个独立面板。预设合并参考敏感性，通过池化一阶、二阶矩计算总方差。预测分数、目标均为四轴命名物理分数。用整条 TEST 轨迹或整参考面板的索引进行重抽样，同一索引共享于全部模型、条件、臂与嵌套窗口。8 个独立参考面板的平均效果同时重抽 TEST 行与 REF 面板；池化参考作为一套固定参考用 TEST 行重抽。报告各参考面板间表现离散程度。所有总体先等权平均同一编码器的读出种子，再等权平均编码器。统计区间条件于这些固定编码器和拟合读出。

记录准确率、配对修复和新增错选、逐轴增量残差 MSE、动态分子和归一化慢度 MAE 及有符号均值误差。令真实集合外最小预测分数减真实集合内最大预测分数为预测的带符号跨界最小间隔，负部负担为其取负后截断为非负。另报真实间隔 ≤ .01、(.01,.03]、>.03 三层的对比，以及最快轴误纳入和误排除。真实动态分子和总体方差替换构成 2×2 对照，用于揭盲后归因。降低平均增量误差本身不足以判定排序改善。

主判定要求历史强恢复组的两个配对 top-2 增益点估计均至少 1 个百分点，且两个经 Bonferroni 调整的 97.5% 单侧配对重抽样下限都大于零。负部负担与动态 MSE 并列报告。该主比较估计各训练流程的总效应。近似状态匹配门须独立报告，作为区分状态恢复差异的一项诊断。若主判定未满足，保留全部两两效应、匹配与参考敏感性。所有用于规则选择的训练与 VAL 结果不接触 TEST 物理目标，且本分析不据评价改臂或调整 λ。
