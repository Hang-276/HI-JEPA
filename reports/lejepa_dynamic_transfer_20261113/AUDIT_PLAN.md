# 冻结 LeJEPA 动态读出的独立审计计划

日期 2026-11-13。主问题是在同等状态标注、读出和优化预算下，对齐真实多时距增量能否改善新窗口上的命名 top-2，并减少使慢轴与非慢轴翻转的方向性误差。理论背景见[慢度误差分解](../lejepa_mechanisms_20261113/MECHANISM_ACCOUNTING.md)。本文件记录设计审计与正式选型的衔接。实际执行以[拟合协议](experiment/PROTOCOL.md)与[评分协议](analysis/PROTOCOL.md)为准。

## 处理臂与状态可比性

- 固定旧 16 个编码器，各用两个固定探针初始化。所有处理使用同一批 CAL、VAL、REF、TEST 与配对端点索引，且预设更新次数相同。状态对照也前向同一当前、未来端点，并对端点平均计算状态 MSE。各 lag 按同一权重进入动态目标。标准化参数、超参、探针选型不接触 TEST。
- 记一个端点的状态残差为 $e=u-z$。在同一个配对批中，若 $L_{state}=(E[e_t^2]+E[e_{t+h}^2])/2$ 且 $L_{inc}=E[(e_{t+h}-e_t)^2]/2$，则 $L_{inc}=L_{state}-E[e_te_{t+h}]$。因此动态臂也改变有效状态损失权重和梯度尺度。若使用 shuffled 对照，应在 lag 层内错配完整未来端点，即观测及其物理标签一起移位。正式错配对照对随机抽得的批次循环移位一个位置，并同时移动未来预测与对应标签。它没有批次位置固定点，但仍可能偶然来自同一轨迹。各臂保持同一状态项，并用 $1+\lambda$ 归一化组合损失。
- 正式协议固定所有臂为第 3,000 步参数及共同学习率计划，VAL 仅监测并用于匹配，不选择权重。主对比为 λ=1 对状态臂及同系数错配臂，λ=.1 只报告描述性剂量结果。
- 逐轴 VAL R² 绝对差最大不超过 .005 的配对可作为状态恢复近似匹配。用 VAL 全轨迹而非训练 minibatch 统计，并预先指定足够的 checkpoint 数、条件覆盖及每模型两个探针是否都须过门。将所有预定配对保留为主要总体。匹配子组属于按拟合后 VAL 指标限定的次要总体，不能用它挑选 λ 或暗示已经隔离全部状态恢复差异。未达到样本覆盖门槛时，仍报告全体总效应和匹配失败数。

## 目标、诊断与判定

- 主终点固定 193 状态窗口的真实命名 top-2，65/513 状态结果为预设长度敏感性。物理方差固定 1。每个探针在同一份独立 REF 的预测坐标中估计自身方差。对同一已冻结读出同时使用各 REF 面板，分开记录动态分子与参考方差。统计同一测试上的正对负、负对正和净差。
- 增量残差能量下降只说明 $E[(\Delta e)^2]$ 下降。慢度分子的有符号偏差还含 $2E[\Delta z\,\Delta e]$，预测参考尺度又可放大或抵消它。记录分子误差、分母误差及交互，保留有符号量。对每个真实慢轴 $i$ 与真实非慢轴 $j$ 计算物理差 $D_j-D_i$、预测差和有害方向误差 $(\widehat D_i-D_i)-(\widehat D_j-D_j)$。负的预测跨界最小差或按预设平局规则发生的并列才触发名次错误。额外报告跨界最小差的负部平均、真实 gap 分层，以及最快轴错误纳入与排除。仅报告平均动态 MSE、整体 gap MAE 或状态 R² 不足以建立排序改善。
- 正式主判据为历史强恢复组两项 top-2 点差至少各 1 个百分点，且两项单侧 97.5% 下限均大于零。跨界误差用于检验观察到的排序变化是否与机制一致。若两者不同向，保留结果并解释证据范围。若与 shuffled 的区别不成立，观察改善仍可来自损失尺度、一般正则或与初始化相关的训练行为。逐窗真值代数重构或替换真实分子、分母均为事后诊断，不产生前瞻保证。

## 随机流、封存与统计单位

- 新 master 2026111304 与既有实验区分。CAL、VAL、REF、TEST、端点采样、置换和重抽样应按角色拆分。确认按轨迹分割。若各动力学条件共用基础创新以便配对，记录并沿用同一行身份。65/193/513 的前缀共用同一条测试路径。
- 预测阶段将同一窗口所有臂的状态预测或分子、参考方差、模型与协议散列封存。独立评分阶段按封存索引回放物理目标。若有参考无效值，记录对应臂、面板和处理规则，不应用 epsilon 伪造有限慢度。
- 主要不确定性是新测试轨迹和参考估计。整 TEST 轨迹和整 REF 面板可作两个重抽样维度，并在共享的各臂、模型、窗口长度和随机种子上同步抽样。不能把共享同一 TEST 的多个 REF 评分、同一条轨迹内的时间点、探针重复或嵌套窗口当作独立轨迹。报告每模型、训练条件及探针 seed 的结果。区间条件于固定编码器与拟合探针，且八个参考面板提供的参考样本变异估计有限。
