# LeJEPA 自然残余误差：低阶状态交互是否是关键原因

日期：2026-11-13。本地实验已完成，主检验两轮均未通过。旧实验和模型权重未修改。

## 先确认研究对象

**目前确实在用 LeJEPA 做研究。** 当前编码器按可辨识性论文作者的实现训练，直接使用其对齐损失、SIGReg 和 MLP 构造。本研究设定四因素数据、观测变换和本地训练规模。本轮复用其中 14 个历史强恢复模型的冻结监督 MLP 读出，编码器和原读出都不重训。

因此结论属于 LeJEPA 的本地低维机制研究，还不是视觉任务验证，也不是无标签修正方法的结果。代码、实际训练记录和适配范围见 [LeJEPA 身份核验](LEJEPA_SCOPE.md)。

## 我们得到了什么结论

**强读出中确实能找到随多个因素共同变化的残差，但修正本轮选定的二、三阶交互组，没有稳定改善慢因素选取。** 两轮正确率分别变化 **+0.021 和 −0.051 个百分点**，两个置信区间都包含零。

更有解释价值的是，使用真实物理因素来扣除这组误差的诊断，也没有稳定收益，尽管它确实降低了状态恢复误差。因此，这次失败不能只归咎于可见代理估计得不够准。我们定位到了某些自然误差，但尚未定位到足以明显减少剩余错选的误差方向。

## 这次检查的误差是什么

上一轮研究的是固定比例混入，例如第 3 轴总带一点第 2 个因素。本轮研究更复杂的情形：某个因素的估计被放大或缩小多少，会随另一个因素的状态变化。例如形如 z_j(z_d²−1) 的误差，就是供体 d 的大小改变了受体 j 的估计幅度。

在正式实验前，使用独立校准状态及 64 条探索性验证轨迹提出假设。这些探索数据也计算过状态、增量及慢度分数误差，不属于正式 TEST，不计入确认性结论。单个最大残差项的身份不够稳定，所以正式方案预先固定整个二、三阶多因素交互组，共 22 项；没有在正式测试结果出来后挑选有利项。

主方法只修正第 2、3 个轴中的这组误差。系数由带物理标签的 CAL 决定，实际应用只访问模型输出。还安排了单轴修正、反向修正、单轴自身曲线、未经代理校准的修正、全部二三阶修正等辅助对照。所有分支采用各自坐标的独立参考方差。真值诊断只能用于解释，不能当作可实现方法。

## 两轮独立结果

| 指标 | 首轮 | 第二轮 |
|---|---:|---:|
| 原读出选取正确率 | 94.00% | 94.12% |
| 交互组修正后正确率 | 94.02% | 94.07% |
| 相对原读出的净变化，百分点 | +0.021 | −0.051 |
| 净变化的配对 95% 区间，百分点 | [−0.096, +0.134] | [−0.166, +0.058] |
| 修复旧错选／新增错选 | 249／237 | 232／261 |
| 真值交互组诊断的净变化，百分点 | +0.026 | −0.012 |
| 全部二、三阶可观测修正的净变化，百分点 | −0.009 | −0.061 |

每轮使用 14 个冻结模型、两个既定过程、每过程 2048 条新轨迹。计数跨 28 个模型与过程组合汇总，但模型和过程共享底层创新行，不能把所有组合当独立样本。区间按整行配对抽样，条件于固定模型以及各轮的 CAL、REF。

预设实效标准是相对原读出及反方向各至少提高 1 个百分点，且区间下限为正。主方法两轮都未达到。单轴修正、自身曲线和其他辅助分支也未给出跨两轮稳定的正向选取收益，不能用其中某一轮的改善替换主检验。

## “修正有没有成功”也要单独回答

这里的减半指选定交互组的系数向量范数至少减半，并不是整个恢复误差减半。

- 首轮，28 个不同的“模型×受体轴”都接受修正，其中只有 **19/28** 在独立状态上达到组范数减半，未达到预设的 80% 标准。
- 第二轮，26 个不同的“模型×受体轴”接受修正，其中 **25/26** 达到减半；修正目标大部分实现，选取仍未改善。

两个过程复用同一模型的校准和状态审计，不能把上述数量翻倍称为额外独立验证。CAL 上的抵消有一部分来自拟合构造，只有独立状态审计才提供检验证据。

使用真实物理因素的交互组诊断，在两轮 TEST 轨迹上都降低了两个受体轴跨固定任务平均的恢复 MSE，幅度约 5%–6%，但对应的选取收益仍仅为 +0.026／−0.012 个百分点。全部二、三阶可观测修正也降低了两轴的 TEST 状态 MSE，排序却没有稳定变好。这是本轮关于“恢复误差改善不自动转化为可靠慢集”的直接证据。

独立 iid 审计与 TEST 轨迹上的有限样本状态 MSE 也需分别报告：主交互修正在 iid 审计上改善两轴 MSE，但在 TEST 轨迹上并不一致。两者来自同一平稳边际分布，不能把这种样本差异写成已确认的分布漂移。完整数值见 [独立评分报告](SCORING_RESULTS.md)。

## 揭盲后的诊断：是否还有继续研究恢复误差的空间

主实验结束后，另做了一项只用既有数据的解释性对照：将窗口读出和参考样本的坐标都替换为真实物理状态，仍保留原来 32768 个 REF 样本预算。没有重训、追加种子或改变主检验。

这个对照的正确率为 **97.49% 和 97.41%**，比原读出分别高 **3.49 和 3.29 个百分点**。原读出与真实坐标对照之间仍有差距，而本轮的低阶交互组修正没有取得相应改善；差距的具体来源仍需拆分。

真实坐标对照本身也不是 100%，其剩余错选来自有限 REF 方差相对物理总体方差的偏差。它不是理论性能上限，也不能把它与原读出的差值直接拆成“分子误差贡献”和“分母误差贡献”；两类误差可能互相抵消。该对照使用测试真值，只是揭盲后的诊断，不能当作方法收益或替代失败的主检验。见 [同参考预算的物理坐标诊断](POSTHOC_PHYSICAL_REFERENCE.md)。

## 对研究路线的帮助与剩余问题

目前可以明确三件事：

1. 较明显的自然线性串轴已经得到定向干预支持；它能解释一部分命名读出的错选。
2. 对强非线性读出，继续削弱单条小线性混入，或本轮预定的低阶交互组，都没有带来稳定实效。不能把这些已定位的残差直接当作剩余错选的主要原因。
3. 本轮检查只覆盖有限阶残差的一部分。它没有否定全部状态相关误差，也没有证明高阶项一定是答案。恢复坐标和有限参考共同作用后的剩余错误仍未解释完整。

因此下一步仍留在 A1：先在独立校准轨迹中找出**哪些残余误差真正把候选因素的慢度分数推过入选边界**，再做定向干预。不能仅凭静态恢复误差较大来选择修正方向，也不继续靠增加多项式阶数寻找有利结果。本轮所有失败和辅助结果保留，A2 尚未启动。
