# 状态相关残差实验的独立审计

核验对象为两轮正式的 [设计锁](DESIGN_LOCK.json)、[预测回执](forecast/RECEIPT.json)、[揭盲回执](REVEAL_RECEIPT.json) 和 [评分数据](SUMMARY.json)。结果复算只读取封存工件，没有重复运行正式实验。

- 核验了 97 项来源哈希、112 项正式预测工件的精确文件集合和内容，以及设计、预测、真值与结果之间的哈希链。28 个组合恰等于上轮父实验冻结的 MLP 子集。所有共享源哈希与前一设计锁一致，旧自然误差方向归档的 391 项校验记录全部通过。
- 正式主种子为 2026111316 和 2026111317，CAL、REF、TEST 和 AUDIT_STATE 使用各自独立的角色流。两轮分别拟合 CAL，两个评价过程使用同一模型的同一 CAL、REF 及状态审计结果。预测阶段通过冻结观测及读出获得 TEST 可见坐标，未计算物理慢集或调用真值供体。全部预测封存后，另一进程重放并保存物理状态供评分使用。锁定的正式脚本和协议从预测到揭盲无变更。
- 工程检查使用另外生成的 iid 状态，验证了 35 列基、22 项交互分组、校准后修正量的线性物理载荷、沿目标系数向量的投影，以及相反更新量的对称性。正式复核再从保存的 CAL 参数重算所有资格和相应组索引。CAL 上代理余弦至少 .9 与投影缩放共同构造出至少约 51.6% 的组范数下降。实证衰减以独立 AUDIT_STATE 拟合出的整个组范数为准。
- 使用每臂自身的保存 REF 方差和动态分子复算全部分数，逐窗验证固定排序规则。逐轴标准化前后的基线分数最大差为 6.93e−14。从揭盲的物理坐标直接计算方差为 1 的真实 top‑2，复算八个可观测分支的正确、修复、新增错误、净变化和换入换出共现计数。用保存的独立状态回归系数核验了真值诊断仅改变指定 Hermite 系数，最大误差为 1.86e−16。
- 从两个过程的轨迹反推并核对共享创新行。先逐行对固定组合求配对差，再用相同的 4096 次整行重采样复算区间。所有全量、活跃和按过程的可观测分支结果均与正式评分一致。区间条件于当前冻结读出及每轮固定 CAL/REF，适用于新轨迹行取样。
- 正式前的探索使用种子 2026111396 的 CAL、VAL 和独立角色生成的 64 条探索窗口。这些探索窗口使用物理真值计算慢度绝对误差与增量误差诊断，并未进入正式主检验。探索与正式随机流不同，正式协议仅检验预定交互组。

程序中的状态衰减计数按过程记为 38/56 和 50/52，两个过程重复了相同的模型×受体状态检查。每轮排序评价含 57,344 个模型×过程×窗口组合，抽样单位为每轮 2048 条创新行。首轮未达到 80% 的独立衰减门。复验达到衰减门，排序净收益仍远低于预设的 1 个百分点。两轮相对原读出的区间均包含零，且上界均低于 +1 个百分点。

正式评分中的真值供体诊断相对原读出为 +0.02616 和 −0.01221 个百分点，区间上界均低于 +1 个百分点。这使得仅用代理不够准确来解释零净收益缺乏支持。真值诊断仍使用 CAL 估计的系数及可观测修正的资格门，不能代表删除全部真实交互。独立状态上的恢复误差变化、组衰减以及窗口净排序收益应分别解读。两轮宽间隔与窄间隔的点估计分别为 +0.140/+0.021 和 −0.098/−0.122 个百分点，各自区间均包含零。单轴分支的收益方向也未在两轮稳定复现。

这项结果排除了当前固定面板上这条双轴校正规则达到预定的大幅平均收益。它仍允许小幅收益和局部修复，也没有建立剩余错选来自哪一种残差。自身单变量项与全低阶项只作辅助。其他物理轴的单变量非线性、高阶尾项、不同状态或更强干预仍超出本轮主检验。

## 揭盲后物理坐标与经验参考诊断

重新核验 [诊断档案](POSTHOC_PHYSICAL_REFERENCE.json) 引用的六项正式工件哈希。使用原 REF 角色 2 和原正式种子重放既有物理参考行，在封存轨迹上独立重算经验参考方差、top‑2 和整行配对区间，未生成新的实验随机流。两轮精确物理坐标加经验参考的正确率为 97.485% 和 97.412%，相对冻结基线分别增加 +3.486 [2.991, 4.019] 和 +3.287 [2.745, 3.831] 个百分点。对应的修复／新增错选为 2481／482 和 2442／557。宽间隔两轮各有 55 个不同窗口仍选错，窄间隔分别有 48 和 51 个。以上数字与 [诊断报告](POSTHOC_PHYSICAL_REFERENCE.md) 一致。

在这一物理坐标对照中，剩余错选来自物理经验方差与目标定义所用总体方差 1 的差异。相对于冻结读出，诊断同时更换了窗口动态分子和参考分母所在的坐标。因此对照差值无法单独归因于某一项，也不能当作任何读出规则的性能上限。新增错选的存在与这些限制相符。

根据正式逐任务记录，真值交互诊断在 TEST 上对第 2／3 轴的平均状态 MSE 分别降低 5.75%／4.94% 和 5.95%／5.62%。实际双轴交互校正在 iid 状态审计上两轴均降低 MSE，TEST 上首轮第 2 轴下降、第 3 轴上升，复验两轴略升。这些数据使用同一平稳边际分布，差异属于有限样本结果，无法据此确认状态分布漂移。
