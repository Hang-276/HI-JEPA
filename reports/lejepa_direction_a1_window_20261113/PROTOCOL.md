# A1 逐窗混轴干预预测

本轮检验同一冻结读出在同一窗口接受混轴后，带符号的跨轴增量项能否帮助预测物理慢集选取的修复和损害。前一轮固定供体的总体风险排序未过门，结果见[前一轮报告](../lejepa_direction_a1_20261113/RESULTS.md)。本轮检验逐窗终点。

## 数据与干预

复用原先 14 个强恢复编码器及其冻结物理 MLP 读出。评价沿用两组共同独立高斯 AR 过程。每条窗口 193 个状态，动态分数使用 lag 4、16、32 等权的平均平方增量。真实物理答案取未混轴的最低两个命名轴，参考方差为 1。排名并列按轴索引稳定处理。

固定第 3 轴为受体，供体为第 1、4 轴，各施加正、负方向，额外状态 MSE 取 .01 和 .04，共八臂。以首轮 32768 个独立状态 CAL 样本估计 b=mean((U3−Z3)Ud) 与 c=mean(Ud²)，分别解 c a²+2ba=τ 的正根和负根。系数在全部评价中冻结。两根通常不同幅。对各模型、过程、剂量和轮次，验证四个臂的 TEST 受体 R² 最大差不超过 .005，保留全部对比。

每模型和过程的物理分数预测器用独立带标签 CAL-fit 256 窗和 VAL 128 窗拟合。固定使用基线读出增量矩的四个对角元素，按 VAL MSE 从相同预设 ridge 候选中选择。这个冻结预测器由全部干预和对照共享。

两轮种子为 2026111310 和 2026111311，各用独立 32768 个 iid REF 状态和每过程 2048 个 TEST 窗口。CAL 和 VAL 仅由首轮独立用途随机流生成。相同行索引在模型、过程、臂内共享基础创新。预测阶段用 TEST 状态生成观测并前向读出，真实物理排名由另一阶段重建。两轮预测和来源文件先一并封存，再揭盲。

## 两个预测规则和物理终点

候选的受体动态分子从基线增量矩 G 预测。完整规则为 G33+2aG3d+a²Gdd。去交叉项规则为 G33+a²Gdd。共同参考分母使用独立 REF 中实际剪切坐标的方差，包含参考协方差。由此只检验动态分子的有符号项。两规则共用系数、干预定义、基线慢集、其他轴分数及 CAL 预测物理慢集。预测阶段从基线矩计算两种假设候选集合，未生成干预后的 TEST 时序。

预测修复、持平或损害，定义为假设候选集合与 CAL 预测物理集合的一致指示值，减去基线集合与同一预测物理集合的一致指示值。评分器独立对读出时序和 REF 逐点施加实际剪切，重新计算分数，并用未混轴的 TEST 物理答案评估同样的差值。基线矩公式与直接剪切排序的一致性是数值核验。主证据来自相对于独立物理答案的三类干预效果预测。

幅度对照保留 |2aG3d|，对其正负两种可能符号分别预测三类效果，以各半权重混合成概率。比较该对照和完整规则的多类 Brier 损失作辅助诊断。它沿用共同参考方差与同一物理预测器。

## 验收与统计

主指标为完整规则减去交叉项规则的三类宏平均召回率差。对每一真类统计全体固定模型×过程×臂×窗口，再等权平均三类召回率。全部窗口进入主指标。每真类每轮至少需覆盖 50 个不同的基础创新行。两轮分别要求提升至少 1 个百分点且 95% 配对 bootstrap 下限大于 0。每轮 4096 次重抽整条共享创新行，所有模型、过程、臂同步，重复中重算各类分母。区间条件于固定模型、初轮校准与本轮 REF。匹配门及两轮预测门均通过时，A1 的新增逐窗验证通过。

报告逐类计数和召回率、全体正确率、方向机会覆盖、真实净效应及强对照 Brier。保留前一轮总体供体风险失败。若本轮通过，完成结论限于当前冻结读出和有标签 CAL 的已知剪切干预。训练误差自发形成的方向及新训练权重的泛化需要另行检验。
