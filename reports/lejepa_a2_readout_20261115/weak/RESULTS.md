# 64 个训练标注的读出校准

固定 A4 的 8 个编码器。每个编码器只拟合一次新读出，使用原训练样本流前 64 个物理状态标签。架构、优化预算、初始化和随机流来源均沿用原拟合器。新读出用 64 样本估计输入的标准化参数。原读出保留原先 8,192 个训练标签和对应拟合参数。两者用同一批 4,096 个独立的验证标签选择检查点。两种读出都在同一批此前未使用的 16,384 个独立高斯状态上打分。该批状态只用于审核，未生成测试轨迹。

减少训练标签后，32 个编码器–物理轴组合的 (R^2) 均降低，但最低仍为 0.968380。separated_wide 的跨轴跨种子均值从 0.997746 降至 0.994203；crossed_wide 从 0.997403 降至 0.989243。crossed_wide 的第 4 轴下降最大，四个种子的降幅为 0.0194–0.0265。这里的审核只度量同一编码器不同标注预算下的静态恢复。

原读出的验证结果已精确重放至 (10^{-12}) 绝对容差。独立加载已保存的两种读出，逐模型重建审核数据与配对预测，复核了 60 项来源和产物散列，并逐项精确重现全部审核 (R^2)。拟合和审核共用时 8.89 秒，使用 2 个 CPU 线程。设计在拟合前封存。逐模型数据、权重和选择轨迹散列保存在 [RECEIPT.json](RECEIPT.json)。
