# 自然误差方向：只削弱一个混入方向是否改善慢因素选取

本方案在新两轮 TEST 揭盲之前锁定。仅本地 CPU；不重新训练 encoder，不改变旧实验。目的是检验冻结模型与冻结命名读出自然形成的误差，不再人为添加一种已知误差。该实验属于 A1，暂不推进 A2。

## 对象与校准

主检验：旧自然实验 primary 中固定的 16 个 encoder × 2 个过程的命名滞后读出。压力检验：先前按历史恢复质量选定的 14 个强 MLP 读出 × 2 个过程。两层分别报告，不将大误差和小误差读出混合平均。主结论限定于冻结命名读出中的线性串轴，不能归因于训练优化本身。固定旧命名变换，因此本轮不是重新寻找有利坐标。

每轮使用独立的 32768 个带物理标签 CAL 状态，前向拟合 U=b+A Z。把每个轴变换为 V_j=(U_j-b_j)/A_jj，所得前向矩阵 F 的对角为 1。该逐轴仿射变换不改变按自身 REF 方差归一化的慢度，也不改变 baseline 慢集。所有分支使用同一批标签；无 TEST 调参或按 TEST 筛模型。

两轮分别重新估计 CAL 系数、检查资格，因此检验的是固定校正程序在新数据上的复现性。两轮均复用原来的冻结模型与命名变换。若原对角斜率绝对值低于 1e-8，归一化数值无定义，整轮停止并报告技术异常，不能删除该任务后继续。

只在预先关注的慢集边界轴 2、3 中选一个 recipient，从其余轴选择 |F_jd| 最大的一项。若 |F_jd|<.01、两个 CAL 半组估计的符号不一致，或任何原对角斜率绝对值小于 .05，则该任务不做定向修正，但仍计入全部任务的总效果。阈值、方向、幅度不使用慢集正确性来调优。CAL 半组仅检查同一项，不搜索替代项。

## 分支

1. base：冻结读出。
2. target：只改坐标 j，V'_j=V_j-c(V_d-mean_CAL(V_d))，c=F_jd。
3. reverse：同一项改为加，更新量大小与 target 完全相同。
4. wrong_donor：在剩余 donor 中取编号最小者，校准其更新方差与 target 相同；最终状态 MSE 不保证匹配。
5. joint_linear：用同批 CAL 标签做联合线性状态解码，仅作普通解混对照。

定向三分支失去资格时均等于 base。joint_linear 无此门槛。所有可用方法只访问可观测读出，不使用测试物理状态。

额外诊断 oracle：在揭盲脚本中用真实 Z_d 代替 V_d。它只移除指定的物理线性分量，用于检查代理 donor 的连带影响，不能列作可实现方法效果。代理 donor 自身含混合，故 target 只修改一个坐标，却未必只改变一个物理载荷；必须量化副作用。

## 评价与证据标准

固定长度 193、lags=4/16/32；每窗各 lag 平均平方增量等权平均，除以各分支在同一批独立 32768 个 REF 状态上的自身方差。物理真值以原物理因素及其人口方差 1 定义，比较最慢两个因素的集合，不能使用新坐标的最慢集合充当真值。每轮 2048 条全新 TEST 创新轨迹，各模型和两个过程共享创新行，因此 bootstrap 整行重采样，不能把模型×过程重复当成独立样本。区间只对当前固定模型面板的新轨迹取样，不涵盖重训的不确定性。

上述区间还条件于已拟合的 CAL 方向和本轮 REF；它不单独估计重复抽取校准或参考数据的不确定性。第二轮完整重做 CAL/REF/TEST，提供另一组重复验证。

独立 AUDIT_STATE 面板重新拟合前向载荷，检查选定混入是否至少减少 50%，以及其他混入、自己的物理响应和状态恢复误差是否变化。CAL 上载荷抵消是拟合代数，不是有效证据。

主读出层的成功需要两轮分别满足：有资格任务中至少 80% 的目标载荷在独立状态上减半；所有任务平均 target 相对 base 正确率提高至少 1 个百分点、配对 95% bootstrap 区间下限大于 0；相对 reverse 也达到相同要求。wrong_donor、joint_linear、oracle、宽窄间隔以及共同 14 个模型比较均为描述性辅助结果，不通过后更换主指标。若只有窄间隔有效，结论须保留该条件。

逐一报告原本正确率、修复旧错选的比例、新增错选的比例和净变化，列出具体物理换入/换出因素。对 MLP 独立执行同样检验，即使混入很小或效果近零也保留。先保存两轮全部可观测分支的预测和文件哈希，再允许独立揭盲；预期机制和全部分支不因第一轮结果改变。

## 预先保留的解释限制

这不是无标签学习方法：定位混入方向使用物理 CAL 标签。反号/错误 donor 匹配修正量，未匹配最终恢复质量；本实验验证移除自然串轴的作用，不重复上一轮固定恢复质量的论证。不能据此声称所有自然误差均已解释，非线性残差与训练误差来源另论。若主门失败，原样记录失败，不扩大模型/种子或修改规则来补显著性。
