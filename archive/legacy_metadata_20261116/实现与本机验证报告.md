# HI-JEPA 实现与本机验证报告

日期：2026 年 10 月 19 日。

proposal 当前三组低维机制实验所需的代码、对照、配置、运行器与评估已实现，并在本机 CPU 跑通完整集成路径。正式实验保留给统一的 Linux CUDA 环境，本次未进行正式训练，也未宣称实验方法有效。

## 交付内容

完整代码位于本目录，入口为 `run.py`。包含 E/G/F、受限实／旋转缩放块 K、状态复合 rank、逐块定标、原算法 SIGReg、固定 covariance floor、目标谱选择与兼容性审计、5 种模型、三个实验的配置矩阵、calibration 冻结匹配、原始空间预测、细节保留、迁移成本、跨种子一致性、恢复 checkpoint 与跨设备数值对齐。

`README.md` 给出安装、运行和迁移入口；`docs/PROTOCOL.md` 区分 proposal 规定与本次实施选择；`configs/` 保存本机和正式预算；`validation/` 保存本次证据。

## Linux CUDA 阶段

正式矩阵为 19 个设定、3 个 seed，共 57 条计划记录。CPU 数学预检显示 14 个设定可认证、5 个设定不可认证；困难条件原样保留。当前预检可训练部分包含 42 条记录，其中 3 条复用既有源结果，即最多 39 次独立源训练；full/no_fine 另有 6 次迁移。

源预算每次 20,000 步，迁移最多 10,000 步，3 个 seed；数据为 4096/512/1024 条独立 train/calibration/test 轨迹。正式数据 seed 与本机集成分开。完整预算约为 840,000 次更新，以验收通过、预检状态未变且所有任务执行为条件。GPU 时长仍未实测。

在解压后的项目目录安装依赖后执行：

```bash
bash scripts/run_formal.sh runs/formal
```

脚本先检查 CUDA，再用随附的固定 checkpoint／batch 做 CPU→CUDA 前向、各项损失与梯度对齐，随后冻结 manifest 并运行正式矩阵。任何一步失败即停止，不静默改设备或删约束。源码与配置没有开发机绝对路径。

各实验的独立 shell 入口、全部实验入口及仅生成清单模式见 README 的“各实验启动脚本”。子矩阵会自动加入必要基准，继承 canonical 配置而不改变预算；生成的 base 和子矩阵使用相对引用，可随结果目录整体迁移。三组实验的 formal/local 八种组合均已验证，没有启动正式训练。

本次没有实际执行 CUDA、构建 Docker 镜像或测试远程机器的驱动环境。这些检查在目标平台完成；已提供 Dockerfile、精确主依赖版本和独立 parity bundle。

## 证据范围

谱选择证书限定于声明的局部查询、C3 和浮点误差模型，未采用 directed-rounding 区间算术。训练后局部残差、跨种子指标和光滑性预算都不能自动成为完整有限样本恢复证明。完整比较解 joint cost 与学习恢复证书仍保留未知。

当前交付不包含视觉、自然任务、控制或动作因果辨识的实验结论。正式结果统一从 Linux CUDA 阶段生成，本机集成记录始终单独标注为工程证据。
