# HI-JEPA 执行协议

本协议对应 2026-10-18 在线 proposal 的第 2 至第 4 节，并落实用户随后确定的边界：本机完整实现与集成跑通，正式实验统一放在 Linux CUDA。不会在本机生成或宣称正式研究主结果。

## 已定方法

- 底层一般非线性预测，高层恢复部分模态；K 为实块及旋转缩放块。
- q 保留 1，另加 k、2k。rank 作用于 G∘E∘g 的状态导数。
- 实模态逐维、振荡逐块定标，不跨模态联合白化。
- 固定 0.1 SIGReg(z)＋高层 covariance floor；floor 标准差 0.2、epsilon 1e-6、权重 1。
- 谱选择只用训练可访问信息；局部查询权限与误差预算对所有对照相同。
- train 按独立轨迹划分；calibration 拟合匹配，test 冻结使用。
- 实验二共享目标选择与防坍塌配置，不把共享 floor／谱域排除误归因于 rank。
- 实验三匹配直接模型的高层容量，另用同 E/G/F 去细粒度源 loss 的对照；迁移冻结 G/K，仅更新 E/F。

## 本次实施选择

proposal 未指定的数值写入 JSON 并冻结：系统维度、谱与扰动网格、轨迹数量和长度、种子、网络宽深、更新次数、Adam 学习率、rank/scale 权重、k、局部访问误差、投影数、读出与迁移阈值。它们不是 proposal 原文规定的常数。

源与目标分支共享当前参数，target 值 stop-gradient，无 EMA 偏差。MLP 使用 tanh；每个 Linear 的权重 Frobenius 范数及偏置 L2 上限为 8，优化后投影。该约束提供统一的 C1,1 预算，不是新增损失或新理论保证。

正式配置：z=32，E/G/F 各两个 128 宽隐藏层，batch=256，源训练 20,000 次更新；train/calibration/test 为 4096/512/1024 条独立轨迹，长度 64，3 个 seed。迁移目标 train=512，最多 10,000 次更新，每 250 步检查冻结读出下的 calibration monitor。读出使用固定 ridge 和样本预算。

本机配置：相同方法与评价流程，网络与数据预算较小，两个 seed、每个源训练 256 步，迁移 128 步。这套配置只用于完整路径集成，不能作为正式实验或正式防坍塌验收通过的替代。

## 正式矩阵

矩阵覆盖：基准谱、三档缩小簇内间隔、三档缩小簇外间隔、三档观测噪声、振荡块、重复谱不可分型和局部访问不足；三种实验二模型；实验三 direct/no_fine/full 与所需 full/no_fine 迁移。共 19 个设定、3 个 seed、57 条计划记录；完全相同的源结果复用。

在当前声明的局部查询预算下，CPU 预检有 14 个设定可认证、5 个设定不可认证。不可认证条件保留；其中近重 gap=.008/.002 的失败条件与可认证 gap=.012 条件同时存在。预检没有运行正式训练，也没有调用 CUDA。

e2_full 与 e1_baseline 在相同种子、数据、模型和源训练协议下完全一致，因此复用该源结果，并在记录中注明，不当作独立重复。

正式运行前先生成 manifest 逐项检查。不可认证条件保留为 unresolved，不能为让认证通过而改网格。主设定的真解 rank、实际 K 内域、逆收缩和局部正规性必须兼容；失败意味着该设定不能被接纳为主理论适用例。高层 floor 代价不强行归零，完整比较解与有限样本证书未建立时标为未知。

第一组的两个验收 seed 仅使用 train 上的独立轨迹随机时间样本计算协方差，并单独检查轨迹内动态变化。工程验收阈值固定为 fine effective rank≥1.5、coarse 最小协方差特征值≥(0.2×0.9)²−1e-6、fine/coarse 动态方差比例各≥0.01。这些检查只用于发现严重坍塌，不证明目标恢复或全部细节保留；完整正式预算未运行前不能宣布通过。本机集成不会根据这些结果重新选防坍塌方法。

## 结果解释

轴级匹配只允许符号和受限排列。振荡和近重簇同时报告子空间、calibration 冻结的一般线性函数簇恢复及映射条件数；正交恢复另作辅助指标。簇内线性／旋转匹配不计为逐轴成功。

迁移的 coarse 阈值是冻结 alignment 下的 monitor MSE，fine 阈值是固定 decoder 下的原始空间 rollout MSE。最终评价的 subspace 阈值使用 sin²，另有独立配置键，不混用量纲。

正式结果限于声明的合成系统、局部查询访问和训练预算。预测好、复用快或者某个种子收敛，均不能单独替代可辨识性证据。
