### 1.3 S1 关键结论与严谨注释
1. **彻底推翻维度混杂假说**：在严格相等的 **192 维** 下，`H-JEPA L2` 的 `grid4x4_pca192`（无论 `MLP` `0.9946` 还是纯线性 `Ridge` `0.9195`）与 `grid4x4_rand192`（`MLP` `0.9171`）**`100% (9/9)` 通过全套门一+门二验证（错选 `0/9,069`）**，而同维 `cls` 即使给足 `160,400` 帧仍卡死在 `0.1799`。并且 `grid4x4_pca192` 仅需 **`n = 1,024` 帧即跨过 `0.85` 门槛（`0.8855`）**，样本效率比 `lewm cls`（需 `n = 4,096` 才过门）还高。
2. **线性子空间依赖性（诚实边界）**：`rand192 + ridge` 在三族中共有 **8/9 未过门**（仅 `hjepa_l4 seed44 = 0.8723` 通过；`lewm_seed43 = 0.849850` 差 `0.00015` 未过 `0.85`）。说明 192-D 随机正交投影虽在信息上无损（同基上的 `rand192 + mlp` `9/9 PASS`），但将位置信号分散进了带噪声的方向上，纯线性岭回归需要**对准主方差子空间（PCA192）**才能高效读出。
3. **关于 `grid4x4_3072` 在 S1-B 处于 `0.80–0.86` 的原因说明**（核查自 [s1_fourroom_dim192.py](file:///Users/yuzihang/Documents/ChatGPT/HI-JEPA/results/wave2_server_20261119/light/wave2/s1_fourroom_dim192.py) 与 [fourroom_common.py](file:///Users/yuzihang/Documents/ChatGPT/HI-JEPA/results/wave2_server_20261119/light/wave2/fourroom_common.py)）：S1-B 为了固定计算预算统一设 `steps = 3,000, batch = 128`（而在 `160,400` 帧上 Wave-1 正式 60 epochs 训练为 ~`75,180` 步）；`3072-D` 原始空间输入（未经标准化，首层 `3072×512` 参数比 `192×512` 大 16 倍）在仅 3,000 步内显著欠收敛，而 `PCA192` 的压缩反而把优化难度降了下来，在 1,024 帧 / 3,000 步内就轻松越过 `0.88`。

### 2.1 关键机制洞察：`w_sig` 的非单调表象与三阶段相变（Proposition 4 的完整实证）
乍看之下，`w_sig` 从 `0.0005 -> 0.004 -> 0.02` 时，某些指标似乎呈**“非单调 V 型”**（例如 `seed` 的常规窗误差先从 45% 降回 34%–43% 但 `audit min R²` 先从 `0.45–0.73` **跌到 `~0.0`** 再跃升至 **`0.82–0.99`**；`varR` 先从 `0.54–0.67` **崩到 `0.006–0.008`** 再恢复到 `0.89–0.98`）。正交分解精确揭示这背后是清晰且符合优化理论的 **三个物理相（Phase）**：

1. **Phase 0（`w_sig = 0.0005` 弱正则相）：全局近坍缩与慢快混叠（`15/15` 被门一拦截）**
   - 因为 `SIGReg` 权重过低（`0.0005`），优化器优先把预测 matching loss 压到近零（终步 `matching ≈ 0.0005–0.015`，而未加权的 `SIGReg` 飙升至 **`104–145`**）。
   - 表征呈现全局压缩但未彻底死轴，`slow R² ≈ 0.60–0.64`，`fast R² ≈ 0.55–0.68`，**线性慢信号泄漏高达 `22%–30%`**（`Mixed` / `Regime II-A` 混合），导致全集与选定集几乎失效（错误高达 `44%–50%`）。
2. **Phase I（`w_sig = 0.004` 中间瓶颈相）：慢轴优先恢复 + 快轴主动放弃 → 选择性触发 Regime II-B（`15/15` 被门一拦截）**
   - 当 `w_sig` 升至 `0.004`，`SIGReg` 被压低一个数量级以上（`4.2–12.9`）。编码器发现：**把算力优先用于匹配慢因子 (`slow R² = 0.996–0.998`) 的预测增益远大于快因子**；对于远距离预测误差更大（更难对齐）的快因子（`rho=0.78, 0.76`），优化器在 `lag = 1, 4` 上将其方差几乎彻底坍缩（**`varR = 0.006–0.008`, `fast R² ≈ -0.008..0`**），并用微弱的**高次非线性慢谐波（`harmSl = 0.42–0.47`）**填补正则项空间，直接重现 Proposition 4 的 **Regime II-B**（`lag=4` 时 `5/5` 全为纯 II-B，`lag=1` 时 `3/5` II-B + `2/5` II-A，常规窗错误率高达 `34%–43%`、`local_flip` 错选率 `~70%`）！
   - 注意一个微妙现象：`lag = 10, w_sig = 0.004` 时 `matching` 反弹至 `1.02`，迫使快轴局部保留微小残差（`fast R² = 0.09–0.46`，仅 `seed201` 为 II-B，其余 `4/5` 转入 **Regime II-A** `residual = 0.53`），再次证明“长步长退化”与“过度压缩”沿 II-A / II-B 两条分支交界演化。
